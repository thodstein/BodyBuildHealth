## 1. ОБЩИЕ ПРИНЦИПЫ

### 1.1 Ключевое отличие: женщины ≠ маленькие мужчины

| Параметр | Мужчина | Женщина | Множитель |
|----------|---------|---------|-----------|
| Вирилизация | Не применима | КРИТИЧНА | ∞ |
| Порог гепатотоксичности | Базовый | 0.5× | 0.5 |
| Порог липидного удара | Базовый | 1.5× | 1.5 |
| ЛПВП защита | Низкая | ВЫСОКАЯ | — |
| E2 критичен | Нет | ДА (кости, либидо) | — |
| HPTA ось | Подавляется | Разрушается | — |
| Восстановление | 4–12 нед | 3–6 мес | 2–4× |

### 1.2 Правила «красной линии»

1. **Любая женщина на андрогенах** = Virilization Score мониторинг
2. **Гематокрит >52%** = СТОП + флеботомия
3. **АЛТ >3× ВГН** = СТОП оралов
4. **Голос огрубевает** = СТОП ВСЕГО (необратимо)
5. **Аменорея >6 мес** = гинеколог/эндокринолог

### 1.3 Обязательные флаги в UI

```
ЖЕНЩИНА + Trenbolone    → 🔴 "АБСОЛЮТНОЕ ПРОТИВОПОКАЗАНИЕ"

ЖЕНЩИНА + Метан >10мг/д → 🔴 "НЕДОПУСТИМО"
ЖЕНЩИНА + Тест >25мг/н  → 🟠 "РИСК НЕОБРАТИМОЙ ВИРИЛИЗАЦИИ"
ЖЕНЩИНА + Стан >20мг/д  → 🟠 "ВОЗМОЖНО СНИЖЕНИЕ ЛИБИДО"

## 3. РАСЧЁТ VIRILIZATION SCORE

### 3.1 Формула

```
Virilization Score = Σ (dose_ratio × androgen_index × exposure_multiplier × sensitivity_factor)

Где:
- dose_ratio = actual_dose / virilization_threshold_red (для вещества)
- androgen_index = андрогенный индекс вещества (0–1, где 1 = тестостерон)
- exposure_multiplier = duration_weeks / 4 (линейный рост)
- sensitivity_factor = 3.0 (для женщин, vs 1.0 для мужчин)

Score 0–100:
  0–20  🟢 Безопасно
  20–40 🟡 Внимание (мониторинг)
  40–60 🟠 Риск (снижение дозы)
  60–80 🔴 Высокий риск (отмена)
  80–100 🔴 КРИТИЧНО (необратимо)
```

### 3.2 Андрогенные индексы

| Препарат | Androgen Index (0–1) | Примечание |
|----------|---------------------|------------|
| Тестостерон | 1.00 | Базовый |
| Нандролон | 0.35 | 19-нор = слабее |
| Дростанолон (Masteron) | 0.30 | DHT-производная |
| Оксандролон | 0.24 | Низкая |
| Станозолол | 0.30 | DHT-производная |
| DHB | 0.40 | 5α-восстановленная |
| Примол | 0.20 | Очень низкая |
| Тренболон | 1.50 | Выше тестостерона! |
| Метан | 0.50 | Ароматизация + андроген |
| Туринбол | 0.25 | DHT-производная |
| Болденон | 0.30 | Умеренная |

### 3.3 Примеры расчёта

**Пример 1: 50 мг Deca/нед, 8 недель**
```
dose_ratio = 50 / 75 = 0.67
androgen_index = 0.35
exposure_multiplier = 8 / 4 = 2.0
sensitivity_factor = 3.0

Score = 0.67 × 0.35 × 2.0 × 3.0 × 10 = 14.07 → 🟢 Безопасно
```

**Пример 2: 15 мг Анавар/день, 6 недель**
```
dose_ratio = 15 / 20 = 0.75
androgen_index = 0.24
exposure_multiplier = 6 / 4 = 1.5
sensitivity_factor = 3.0

Score = 0.75 × 0.24 × 1.5 × 3.0 × 10 = 8.1 → 🟢 Безопасно
```

**Пример 3: 100 мг Deca/нед + 20 мг Анавар/день, 12 недель**
```
Deca: (100/75) × 0.35 × (12/4) × 3.0 × 10 = 42.0
Oxan: (20/20) × 0.24 × (12/4) × 3.0 × 10 = 21.6

Score = 63.6 → 🟠 Риск: высокая зона (сократить длительность/дозы, усилить мониторинг)
```

**Пример 4: 10 мг Test/нед + 50 мг Deca/нед, 8 недель**
```
Test: (10/20) × 1.0 × (8/4) × 3.0 × 10 = 30.0
Deca: (50/75) × 0.35 × (8/4) × 3.0 × 10 = 14.1

Score = 44.1 → 🟠 Риск: тест у верхней границы, суммарно — зона риска
```

**Пример 5: 25 мг Test/нед (ЧРЕЗМЕРНО!)**
```
Test: (25/20) × 1.0 × (8/4) × 3.0 × 10 = 75.0

Score = 75.0 → 🔴 Высокий риск (реально — вирилизация!)
```

### 3.4 Множитель чувствительности

| Фактор | Множитель | Примечание |
|--------|-----------|-----------|

  const breakdown: Array<{ substanceId: string; contribution: number }> = [];
  
  // Множитель чувствительности по возрасту
  let ageMultiplier = 1.0;
  if (input.age < 25) ageMultiplier = 1.3;
  else if (input.age > 45) ageMultiplier = 0.8;
  else if (input.age > 35) ageMultiplier = 0.9;
  
  // Множитель генетической чувствительности
  const geneticMultiplier = input.sensitivityFactors.geneticSensitivity ? 1.5 : 1.0;
  
  // Множитель предыдущих циклов
  const previousCyclesMultiplier = input.sensitivityFactors.previousCycles ? 1.2 : 1.0;
  
  for (const substance of input.substances) {
    const profile = FEMALE_VIRILIZATION_THRESHOLDS[substance.substanceId];
    if (!profile) continue;
    
    // Абсолютное противопоказание → score = 100
    if (profile.femaleContraindicated) {
      totalScore = 100;
      breakdown.push({ substanceId: substance.substanceId, contribution: 100 });
      continue;
    }
    
    const doseRatio = substance.doseMgPerWeek / profile.virilizationThresholdRed;
    const exposureMultiplier = substance.durationWeeks / 4;
    const sensitivityFactor = 3.0 * ageMultiplier * geneticMultiplier * previousCyclesMultiplier;
    
    const contribution = doseRatio * profile.androgenIndex * exposureMultiplier * sensitivityFactor * 10;
    totalScore += contribution;
    
    breakdown.push({ substanceId: substance.substanceId, contribution });
  }
  
  totalScore = Math.min(100, Math.max(0, totalScore));
  
  let risk: VirilizationScoreResult['risk'];
  let recommendations: string[] = [];
  
  if (totalScore < 20) {
    risk = 'safe';
    recommendations = ['Продолжить мониторинг каждые 4 недели'];
  } else if (totalScore < 40) {
    risk = 'caution';
    recommendations = ['Усилить Virilization support', 'Мониторинг голоса/клитора еженедельно'];
  } else if (totalScore < 60) {
    risk = 'risk';
    recommendations = ['Снизить дозу', 'Добавить спиронолактон 25мг/д', 'Мониторинг каждые 2 недели'];
  } else if (totalScore < 80) {
    risk = 'high';
    recommendations = ['Снизить дозу на 50%', 'Спиронолактон 50мг/д', 'Финастерид 1мг/д', 'Рассмотреть отмену'];
  } else {
    risk = 'critical';
    recommendations = ['НЕМЕДЛЕННАЯ ОТМЕНА ВСЕГО', 'Спиронолактон 50мг/д', 'Эндокринолог', 'Оценка необратимых изменений'];
  }
  
  return {
    score: Math.round(totalScore),
    risk,
    breakdown,
    recommendations,
  };
}
```
