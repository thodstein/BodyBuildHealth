# Roadmap — Годовой планировщик: развитие (Aug 2026)

План развития годового планирования: построение тренинга и подстройка под соревнования.
Статусы: [ ] запланировано · [x] реализовано · [~] частично.

## A. Подстройка под соревнования

- [x] **A1. Реверс-планирование от даты** — дата соревнования → авто-неделя (`estimateCompetitionWeek`),
      макро строится от «сегодня» (неделя 1 = сегодня); в карточке соревнования «⏳ до старта: N нед».
- [x] **A2. Авто-тапер к соревнованиям** — в карточке блока тапер-инфо: последние 2 недели перед
      стартом — объём ×0.65/RIR+1 (нед N-1) и ×0.45/RIR+2 (нед N), Bosquet 2005 (паритет `taperCurve`/applyPLTaper).
- [x] **A3. Прогноз ПМ к дате старта** — прогрессия цикла (`meta.correctionPct`) спроецирована на неделю
      старта: «📈 к старту ПМ ×Y» в карточке блока соревнования.
- [x] **A4. Календарь «неделя ↔ дата»** — дата начала в блоках таймлайна («Nн · с dd.mm.yy»),
      линейка дат под таймлайном (5 тиков), дата недели соревнования, экспорт **.ics**
      (`buildMacroIcs`: фазы + соревнования, ICS-экранирование).
- [x] **A5. Дневник двигает план** — (Раунд I) `diaryMacroStats`: сессии sRPE за 7/28 дней,
      ACWR (acuteChronicRatio) в «Итог года» с подсказками («перед пиком снизьте объём»/«обязателен делод»);
      кнопка «📈 По дневнику (нед N)» переводит маркер текущей недели на неделю последней сессии.
      TODO: готовность (readiness/HRV) корректирует объём следующего блока.
