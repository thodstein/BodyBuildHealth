## Вердикт аудита (факты кода)

Текущее (`ArmliftingDiagnosticsHub.tsx:319-593`, `armlifting-diagnostics.engine.ts:208-404`,
`arm-platform.engine.ts:1-167`): ввод кг/сек → `%WR` → weakest/avg → попытки 90/96/102 + LMS +
журнал `he_arm_platform_log` + чек-лист 5 правил + класс + мост `weakpoints+armDiscipline`.
Это **учёт помоста**, а не диагностика: нет точки срыва, нет per-implement разбора техники,
нет тест-батареи, нет мобильности/боли, нет причины отстования, нет коррекции кроме 1 строки
`prescriptionForWeakest`. Для сравнения: `ArmDiagnosticsHub.tsx` (армрестлинг) имеет 12 точек,
углы, VBT, Force, причины, топ-3, симулятор, спец-блок, инъекцию во все недели.

## Интернет-синтез (только проверяемое, 2024–2026)

- **Armlifting USA 2026** (Super Series Rules / Info / Beginners): last-man-standing, 60 сек на
  попытку, промах = выбыл, вниз нельзя; снаряды 2026: Raptor 1.75" 1H, Saxon 3×4, Hub freestyle,
  Country Crush 2H, Grandfather Clock, Anvil, Axle 60мм, Saxon medley 2×5, Fat Gripz DOH;
  классы М 60–125+, Ж 55–100+; только мел, калиброванные диски.
- **IronMind** (RT / Axle / Hub / Block / Silver Bullet rules + CoC FAQ + CTD Cube booklet):
  RT 60мм вращающаяся, центр, thumbless запрещён, ~параллельно земле, 1с локаут, протирка;
  Axle — только DOH костяшки вперёд, без hook/thumbless/лямок, полка на бёдра = нет;
  Hub — все 5 подушечек на базе, «дверная ручка» запрещена, ~параллельно, без протяжки по ноге;
  Block — центр, thumbless запрещён, ~параллельно, без касания тела; Silver — диск 2.5кг в
  закрытом №2 (Ж) / №3–4 (М), новый гриппер, вертикально, касание мизинцем = стоп.
  CTD-куб: сила хвата = prime mover (thumb vs 4 fingers) × позиция (open vs closed) ×
  интенсивность (1RM vs endurance) = 8 типов. Канон тренировки CoC: warm 10–12 → work 5–7
  до отказа 1–3 сета → challenge (частички/негативы/холды), 2–3×/нед.
- **StrongerByScience (Gill 2024)**: support/pinch/crush — разные навыки, слабо коррелируют;
  FDP/FDS — главная сила сгибателей, FPL — большой палец; разгибатели запястья ECRL/ECRB/ECU
  держат позицию — при слабости атлет подключает EDC (разгибает и пальцы) и теряет хват;
  запястье в нейтрали vs сгибе меняет длину FDP/FDS и результат.
- **NSCA (Effective methods of grip)**: flexors — сила, extensors — стабилизация запястья;
  towel-модификации, plate pinch 2 плиты гладкими наружу, flips, carries (farmer 20–50м),
  bottom-up, односторонние; хват в конец сессии, не в начало; 2 сета достаточно.
- **PoinT GO / GoldenGrip / Gripnatic (2025–2026)**: 4 типа (crush/support/pinch/extension);
  дисбаланс flexor>extensor → lateral/medial epicondylitis; экстензия с резинкой 15–25,
  кистевой роллер, wrist curls 12–15; support — 30–60с холды, pinch — 20–30с, crush — 5–8;
  сухожилия адаптируются 8–12 нед — грузить постепенно, 2–3×/нед.

## Решение

- Всё текущее — в **одну вкладку «🏟 Помост»** (замеры, %WR, LMS, журнал, правила, класс).
  Строки/aria/хуки/тесты — 1-в-1, ничего не теряем.
- NEW вкладка **«🔍 Диагностика»**: снаряд → точка срыва → фолы техники (per-implement чек-лист
  из правил IronMind/AUSA) → тест-батарея (pinch-hold, farmer-hold, wrist ext, асимметрия из
  помоста) → мобильность (большой палец, разгибание/сгибание запястья, T-spine, hip hinge) →
  боль/флаг → диагноз (слабое звено + причина + уверенность).
- NEW вкладка **«🔧 Коррекция»**: топ-3 коррекции под слабое звено (протоколы CoC/NSCA/SBS
  строками, без новой математики) + мини спец-блок 4 нед (волна 3/2/1) + кнопка в конструктор
  (мост обогащён, старые поля целы).
- Честные границы: разрядных таблиц нет (только лидерборды) — % не выдумываем; Silver/CoC —
  ordinal/время, не норматив; VBT/видео-углы — не тянем (нет LVP-профилей RT/pinch).
