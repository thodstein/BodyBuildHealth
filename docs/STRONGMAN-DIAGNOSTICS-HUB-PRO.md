## §2. Интернет-синтез (что наука требует, а хаб не делает)

1. **Лог: диаметр решает** (Renals 2018, JSCR: малый лог +6% мощность, +2%
   скорость, +5% импульс, +3% сила vs большой; штанга выше лога по всем
   фазам; Winwood 2014: у лога больше сгибание колен во 2-й тяге и разгибание
   таза/колен + вертикаль корпуса в стойке). Хаб спрашивает диаметр, но не
   масштабирует попытки/скорость по диаметру.
2. **Йок: нормы Хиндла** (Hindle 2021, Frontiers/PMC8107362, 19 атлетов, 85%
   1ПМ, 20 м): сгибание таза + лёгкое/нейтральное сгибание колена в касании;
   лёгкое/нейтральное разгибание таза + сгибание колена в отрыве; умеренная
   амплитуда; высокий темп + опора, короткий шаг. Йок 1.14 м / 1.62 Гц /
   0.42 с vs фермер 1.54 м / 1.89 Гц / 0.32 с. Топ-атлеты: длиннее шаг +
   выше темп + короче контакт; пик скорости поздно (17–20 м), у слабых —
   в середине. Хаб не меряет шаг/темп/контакт и не режет дистанцию на
   отрезки 0–5/5–10/10–15/15–20 м.
3. **Фермер: стадии** (Keogh 2014, MDPI Sports: 2.41 → 3.29 → 3.15 м/с по
   стадиям 0–3/8.5–11.5/17–20 м; +48–61% темп, −27–36% шаг vs ходьба;
   дорсифлексия/колено/бедро вверх, наклон корпуса вниз). Хаб не делит
   переноску на разгон/макс/финиш.
4. **Камень: 5 фаз + половые различия** (Hindle 2021, PeerJ/PMC8418215, 20
   атлетов): восстановление → хват → 1-я тяга → колени → 2-я тяга; макс.
   сгибание таза + среднее колена + тыльное голеностопа на старте; среднее
   таза/колена + подошвенное на коленях; среднее таза + макс. колена +
   тыльное на 2-й тяге; макс. разгибание в конце. Женщины: больше сгибание
   таза, короче 2-я тяга (антропометрия). Камень — самый травмоопасный
   (опрос 213 атлетов Winwood 2014: 82% травмированы; поясница 24%,
   бицепс/колено по 11%), хотя компрессия поясницы ниже всех (спина
   обнимает камень). Хаб: пол атлета живёт только в видео, на скоринг/
   попытки/нормы не влияет.
5. **Бицепс: механизм и цифры** (IJSPT 2025 Lorenz: согнутый локоть +
   супинация + пиковая тяга; альтернатива — эксцентрик на разогнутой
   супинированной; Kapicioglu 2021: становая разнохватом; стронг-травмы
   бицепса выше ТА/ПЛ/ББ; 91% травм на ≥90% 1ПМ; шина + камни — слабые/
   уставшие бицепсы не передают силу плеча и корпуса). Хаб: только список
   предупреждений, без количественного риска.
6. **Хват tri-modal канон** (SBS 2024 Nuckols; NSCA Coach: опора — становая/
   тяги/подтягивания/фермер; щипок — диски, выше нагрузка на сухожилия;
   сдавливание — внутреннее сопротивление эспандера; толстый гриф 44–69 мм,
   аксель 50.8 мм). Геркулес: столбы 160 кг; Феликс 87.52 с (2019);
   Уильямс 82.14 с при 159 кг/рука — мировой рекорд WSM 2025. Хаб: нормы
   опоры/щипка/сдавливания есть, холд-диагностики под ивент (геркулес/
   медли) — нет.
7. **Контест-реальность** (WSM 2024/2025, Arnold 2025): медли (йок 454 кг/
   20 м + рама 330 кг; жимовой медли гантель+лог+аксель; каменные медли),
   макс-ивенты (аксель 210 кг; становая 500+ кг), кега в высоту 7.76 м
   (мировой рекорд), геркулес, камни 140–210 кг — решающий ивент,
   переноска бруса 400 кг/11 м в гору, формат «нарастающая штанга» +
   обратный порядок. Хаб: мост попыток не знает формат (макс/повторы/
   медли/высота) и правило «последний идёт первым».
8. **Техника камня Хупера** (Breaking Muscle 2023): руки никогда под камень
   (иначе бицепс держит вес); обхват предплечьями, прямые руки, сжатие
   грудью/широчайшими; становая высоко → колени → бёдра под камень;
   на высокую платформу — руки под 45° сверху. Хаб: чек-лист техники
   камня отсутствует (только смола да/нет).

## §3. План PRO (7 эпиков, каждый — движок + встройка + тест)

- **P1 Диаметр лога в расчёте** (`sm-log-diameter`): масштаб попыток и
  скорости по Renals (малый/большой лог ±%; штанга-опора отдельно);
  паспорт лога принимает диаметр → попытки и VBT-зоны едут. Тест: малый
  лог даёт попытку выше большого при том же 1ПМ.
- **P2 Половые нормы** (`sm-sex-norms`): Хиндл-различия (таз/2-я тяга/
  наклон корпуса) + женские темпы; пол из профиля (не только видео) →
  нормы камня/йока, попытки, порог качания. Тест: женщина vs мужчина —
  разные вердикты при тех же углах.
- **P3 Пофазный тайминг** (`sm-phase-timing`): камень — 5 фаз с длительностями
  (провал = длинная 1-я тяга/короткая 2-я); переноски — отрезки 5 м
  (разгон/макс/финиш, пик поздно = топ). Ввод: 5 чисел времени (HubNum) или
  CSV-тайминги. Тест: пик в середине → вердикт «разгон слабый».
- **P4 Количественный риск бицепса** (`sm-biceps-risk`): баллы (камень в
  плане + разнохват + шина/камень на ≥90% + усталость хвата + анамнез) →
  0–100 + гейт (≥70 — запрет супинации/камня, только лямки/нейтраль).
  Тест: камень + разнохват + 95% → high + гейт в мосте.
- **P5 Холд/медли-кондиция** (`sm-hold-conditioning`): нормы удержания под
  ивент (геркулес 160 кг — секунды; медли — падения/подборы/разворот);
  кондиция медли (рывки с разворотом, а не generic). Тест: холд ниже нормы
  столба → провал + коррекция.
- **P6 Формат-aware попытки** (`sm-format-attempts`): форматы макс/повторы/
  медли/высота + нарастающая/обратный порядок → заявки 85/92/98 только для
  макса; для медли — темп/подборы; для высоты — шаги высоты. Тест: медли
  не получает «попытки кг».
- **P7 Авто-углы из видео** (`sm-auto-angles`): CSV t,таз,колено,голеностоп,
  плечо → ROM йока [30,46]/[43,65] и плечо лога ≥150° автоматом (сейчас
  нормы только текстом); кривой CSV → честная ошибка. Тест: CSV с коленом
  20° → провал йока.

## §4. Осознанно не делаем

- Он-девайс видео (MediaPipe живьём) — только проверка наличия модели;
  углы — через CSV-таблицу (честно подписано «заглушка»).
- Популяционные 1ПМ-нормы по весовым (StrengthLevel) — не калибруем атлета
  по крауду; только его динамика и его рампа.
- Диагнозы травм — только риск-баллы и гейты + «к врачу»; скрининг, не
  диагноз.
- Лямки/экипировка как «исправление» техники — только честный учёт
  (разнохват = риск, лямки = снижение риска, не прирост силы).
