## 1. Аудит хаба (код прочитан, 8 пунктов)

### 1.1. Дозы не по науке, часть — вредные/бесполезные (P0)

`training-mix-scoring.engine.ts:buildDefaultStack` (`:225–459`):

- **Креатин 8 г остро pre** (`:251,318` — PL/competition/sprint): ISSN position stand (Kreider 2017, `PMC5469049`):
  насыщение = `0.3 г/кг/сут 5–7 дн → 3–5 г/сут`; острая разовая 8 г pre **не имеет эргогенного смысла**,
  зато даёт ЖКТ-риск. Фикс — эпик A: 3–5 г/сут в любой тайминг, загрузка только флагом 5–7 дн.
- **Кофеин фикс 200–400 мг** (`:252,265,300,317`): ISSN caffeine (Guest 2021): эффективно `3–6 мг/кг`,
  `<2 мг/кг` не работает, `≥9 мг/кг` — побочки без прироста. Фикс 400 мг для 60 кг = 6.7 мг/кг —
  передоз (тревога/сон/АД; EFSA ≤400 мг/сут, гипертоникам — прессорный эффект Lovallo 3.3 мг/кг).
  Фикс — эпик A/C: `3 мг/кг (макс 400) + чувствительность + гейт АГ/беременность/вечер`.
- **Бета-аланин 3.2–4 г остро pre** (`:253,267,283…`): ISSN beta-alanine (2015): только **хроника 4–6 г/сут
  2–4 нед** (+20–30% карнозина); острый приём не работает + парестезия. Хаб подаёт как «буфер H⁺
  за 30 мин» — вводит в заблуждение. Фикс — эпик A: пометка `chronic-only` + убрать из острого скора.
- **Глицерол 3–5 г** (`:259,289,337…`): литература гипергидратации — `1.0–1.2 г/кг + вода`
  (~70–90 г для 80 кг). 3–5 г = **недодоза в ~20 раз**, эффекта нет. Фикс — эпик A: либо честная
  доза по весу + вода, либо убрать заявление «гипергидратация/венозный памп».
- **HBCD `30–50×durHrs` г** (`:347,356`): при 2 ч = 60–100 г интра без капа/час. Гайдлайн 30–80 г/ч
  (J Nutr 2011; Ramos-Campo 2024 meta 136 иссл.: эффект растёт с длительностью, доза-кап 6–8%).
  Фикс — эпик A: кап `≤60 г/ч`, концентрация 6–8%, ЖКТ-нота.
- **OKG под id `glutamine`** (`:255` — «OKG (орнитин)» с `id:'glutamine'`): неверная сущность —
  ломает скоринг/каталог/конфликты. Фикс — эпик A: отдельный `okg` или честный глутамин.
- **Экдистерон 500 мг + тонжкат 400 мг** (`:261,340`): экдистерон — WADA monitoring program (2020+,
  Parr: +масса/жим, механизм через ER, вопрос включения в S1.2); тонжкат — слабые данные.
  Подача в один ряд с креатином/кофеином — нечестно. Фикс — эпик A: бейдж `evidence: limited/WADA-monitored`.

### 1.2. Скоринг не зависит от дозы (P0, честность)

`calculateMixScore` (`:887–1247`):

- Цикл `:920–930`: `score = baseScore × multiplier`, `doseMg` используется только как `>0`-фильтр
  (`TrainingMixTab.tsx:200`). 1 мг = 10 г — один скор. Бонус `best + (count−1)×5` (`:918`) **надувает
  скор размером стека**, а не качеством.
- `baseScore` — произвольные 62–90 (`SUBSTANCE_DB :102–145`) или `tier→70/60/50/40 + 5×cats`
  (`:97`); ни один порог не привязан к литературе.
- Множитель `isOnCycle ×1.25` (`:888`, `TrainingMixTab.tsx:180`) и модификаторы
  `experience/dayType/timeOfDay/AAS` (`:995–1065, :1101`) — произвольные ×0.85–1.15 без источника.
- Веществ шаблонов нет в скоринге: `green_tea/cla/collagen/glucosamine/msm/probiotic/betaine_hcl/
  bone_broth/glycine/l_theanine/melatonin/gaba/zma/astragalus/echinacea/vitamin_d3/bromelain/
  l_carnitine/waxy_maize/whey_hydro` — `getSubstanceScore` → null → `continue` (`:922`).
  Итог: **пресеты здоровья вообще без скора** (MixPresetsCard его не показывает), а тренировочные
  скоры частично стоят на нулях. Фикс — эпик B: дозо-зависимый скор + покрытие каталога + скор пресетам.

### 1.3. Выход скоринга уходит в пустоту (P0)

`calculateMixScore` считает `recommendedCarbsG/recommendedEAAG/recommendedWaterMl/recommendedNaMg/
recommendedKMg/recommendedClMg` (`:1067–1114`), но `TrainingMixTab` их **нигде не рендерит**
(grep `recommendedCarbsG|recommendedWaterMl` — только дефолтные нули `:215,242`).
Пользователь получает «состав», но не получает «сколько углей/воды/соли» — а это и есть
главное для интра. Фикс — эпик G: блок «Нормы приёма» + мост в питание/поддержку.

### 1.4. Рецепт-движок мёртвый (P0)

`MIX_RECIPES` + `buildBestRecipe` + `groupRecipeItemsByTiming` (`:644–885`): grep
`buildBestRecipe\(|groupRecipeItemsByTiming\(` — **0 живых вызовов** (только barrel-реэкспорт
в `SupportScreen.tsx:53`). Плюс логические баги условий: `insulin_only` требует `d.length===1`
(`:775`) — инсулин+ГПП-1 падает в null; `full_anabolic_cocktail` требует ровно 4 (`:731`) —
5 препаратов (4+ГПП-1) тоже null; `glp1_only` матчит `some(glp1)` (`:840`) даже в комбинациях —
неверный приоритет. Фикс — эпик D: либо оживить как фарма-слой, либо удалить (~220 строк мёртвого кода).

### 1.5. Фарма-риски: инсулин без гейта (P0, безопасность)

- `TrainingMixTab.tsx:164–169`: автоопределение курса ставит **инсулин 5 ЕД / ИГФ-1 50 мкг /
  ГР 5 МЕ / МГФ 200 мкг** дефолтами без ввода пользователя; редактирования доз нет, только
  «Очистить фарму». Рецепты советуют декстрозу `bw×0.5–0.8` (40–64 г для 80 кг, `:676,780`) —
  **дозирование вокруг инсулина без медгейта** (гипогликемия!). `MIX_MECHANISMS/MIX_SYNERGY`
  (`:148–194`) — маркетинговые формулировки («тройной удар», «+2000% биодоступность»,
  «mTOR через ERβ (?)») без грейда доказательств.
- Пресеты: цинк 25–30 мг + ZMA (`:408,447` + sleep `:564`) в один день = риск превышения UL 40 мг;
  витамин C 2 г (`:611,621`); омега-3 3 г + куркумин + бромелайн (`:592–604`) — кровоточивость
  с антикоагулянтами без предупреждения; мелатонин 3 мг фикс (`:554`) — Cruz-Sanabria 2024
  dose-response: пик ~4 мг, приём за ~3 ч до сна (хаб: «за 20 мин» — неверно), плюс возраст/
  беременность/ГПП-1-гейты отсутствуют. Фикс — эпик C: `doctorOnly`-гейты + UL-капы + взаимодействия.

### 1.6. Юниты шаблонов ломают мг и отображение (P1)

`resolveTemplateItems` (`:462–479`): единицы `порц/капс/мл/МЕ` идут как `mg = doseNum`
(ZMA `1 порц` = 1 мг; D3 `2000 МЕ` = 2000 мг — неверно на порядки), а `г/кг` (`protein 0.4 г/кг`,
`:502`) не пересчитывается в абсолют — карточка показывает «0.4г/кг» без граммов, а сохранение
несёт `mg = 0.4`. Фикс — эпик E: канон юнитов + абсолютные граммы в UI и в `mg`.

### 1.7. Петля эффекта — корреляция без статистики (P1)

- `analyzeMixEffectiveness` (`training-plan-save.engine.ts:584–617`): делит сессии по
  `getMixIntake` (любая фаза), сравнивает средние без **минимального N, CI/p, поправки на
  сон/нагрузку**. `MixEffectivenessCard.tsx:17` показывает «📈 объём выше на N%» уже при **1 vs 1**.
- `analyzePresetEffect` (`:475–514`): только sleep/fat_loss/hydration; `after=[]` → `aAvg=bAvg` →
  delta 0 «→» вводит в заблуждение; окно 7 дн фикс; antiinflammatory/immunity/joint/gut — всегда null
  без объяснения. `scheduleMixReminder` (`MixDiarySection.tsx:29`) — `setTimeout` умирает при
  закрытии вкладки, `reminderMsg` один на все записи. Фикс — эпик F.

### 1.8. Хаб-шелл: дубли и отсутствие персиста/экспорта (P2)

- `MixHub.tsx:40–67`: **два селектора режима** (карточки + липкая лента) для 2 режимов — избыточно.
- `PlannerToolsPanel.tsx:58,72`: дубль `id:'mixes'` дважды. Параметры таба
  (goal/timing/тип/время/опыт/день — `TrainingMixTab.tsx:142–157`, `bwInput/mult` —
  `MixPresetsCard.tsx:33–34`) **не персистятся**; `alert()` (`TrainingMixTab.tsx:419`,
  `MixPresetsCard.tsx:81`) вместо тоста; нет HTML/CSV/печати (как у QS/BB-хабов);
  чипы `<div onClick>` без `role=button`/клавиатуры и 44px не везде. Фикс — эпик G.

**Вывод:** хаб хорошо склеен (дневник ↔ избранное ↔ очередь поддержки ↔ фазы приёма —
живой контур), но считает не то: дозы без источников, скор без дозы, рецепты мёртвые,
нормы приёма не показываются, инсулин без гейта.

## 3. Концепция «доза → скор → гейт»

```
профиль (вес, цель, тайминг, опыт, фарма, АГ/беременность/возраст, лабы Na/K/Cl)
        │
        ▼
EVIDENCE_DOSES (S1–S9: доза/кг, кап, chronic-only, evidence-grade)
        │
        ▼
buildDefaultStack v2 (дозы из данных, underdosed-бейджи, chronic-разделение)
        │
        ▼
calculateMixScore v2 (дозо-зависимый: доза/эталон × вес категории; без дозы — 0)
        │
        ▼
safetyGates (кофеин-кап, инсулин-doctorOnly, UL-стеки, взаимодействия, teen/pregnancy/sleep)
        │
        ├─► UI: состав + «Нормы приёма» (угли/вода/соль — из скоринга, мост в питание)
        ├─► дневник/избранное/очередь (как сейчас, + персист/экспорт)
        └─► effectiveness v2 (min N, per-goal, adherence)
```

**Одна фраза:** хаб отвечает *сколько чего и когда по весу и цели — с доказательным грейдом*,
а не *список названий*.

## 5. UI (MixHub, 2 режима сохраняем)

- **Шапка хаба:** чип `evidence-grade` + бейдж `underdosed N` + гейт-чип `⛔/⚠️` (из эпика C);
  дублирующий селектор режима схлопнуть в один (фикс 1.8).
- **Training-вкладка:** дозы `X г (Y мг/кг, эталон Z)` + бейдж `ниже эталона`; блок
  **«Нормы приёма»** (угли/вода/Na-K-Cl из скоринга — фикс 1.3) + кнопки «в питание/в поддержку»;
  фарма-дозы — редактируемые числа с гипо-гейтом, не скрытые дефолты; персист параметров
  `he_mix_hub_v1`; пресеты `competition/post_comp` — в общий селектор целей (сейчас их нельзя
  выбрать, хотя веса скоринга под них есть).
- **Health-вкладка:** скор пресетов (эпик B) + абсолютные граммы (фикс 1.6) + UL/interaction-гейты
  под составом; пустой `intra` у sleep (`:558`) — честная нота «интра не нужен», а не пустота.
- **Дневник/эффект:** adherence (% фаз), min-N для выводов, per-goal split, постоянный
  (а не setTimeout) reminder-флаг; экспорт HTML/CSV/XSS + печать (как QS/BB-хабы).
- **Мост:** `kind:'mix'` + `labDiagnosis`-аналог `mixGrade` в `rationale`; тосты вместо `alert()`.

## 7. Критерии PRO

- Каждая доза показывает `эталон + мг/кг + underdosed-бейдж` при недодозе; chronic-only
  вещества подписаны и не участвуют в остром скоре.
- Скор монотонен по дозе; пресет здоровья имеет скор; `×1.25/×experience` без источника — удалены.
- Нормы приёма (угли/вода/соль) видны и уезжают в питание/поддержку; рецепты либо живые, либо удалены
  (grep — 0 мёртвых экспортов).
- Гейты: инсулин без подтверждения врача — блок; кофеин-кап; UL-стеки; взаимодействия;
  teen/pregnancy/sleep-гейты — все с тестами-мутациями.
- `tsc 0`, `vitest mix` **45+** зелёных (A 10 + B 8 + C 8 + D 4 + E 5 + F 6 + G 7),
  соседи (support-calc, diary, rest-hooks) без регрессий.
- 0 дублей: дозы — из `mix-evidence-doses`, гейты — из `mix-safety-gates`,
  конфликты/UL — из каталога/дозинга.

## 8. Осознанно НЕ делаем

- Свои RCT/мета-анализы и «точные % прироста» из скора (скор — ориентир покрытия, не прогноз кг/ватт).
- Видео/BlazePose-анализ приёма, фото-распознавание банок.
- Персональный фарма-протокол инсулина/ГH (только harm-reduction + «к врачу», дозирование —
  вне скоупа хаба).
- Пассивный стретч-протокол как «микс» (ниша реабилитации — одна нота).
- Своя математика углей/воды вместо §S5 (инвариант питания цел — только показываем и везём).

- `SUPPORT_CATALOG_DATA` неполон по id §1.2 — маппинг делать минимальным словарём, не правкой

  `MixDiarySection.tsx:54` уже есть, не ломать.
