# Тайминг питания вокруг тренировки

## Концепция питания вокруг тренировок

Для оптимизации восстановления и роста мышц важно правильно распределить приёмы пищи вокруг тренировочного процесса.

## Основные приёмы

### 1. Пред-тренировочный приём (Pre-Workout)
**Время**: За 1.5-2 часа до тренировки  
**Цель**: Обеспечить энергию для тренировки, предотвратить катаболизм  
**Состав**:
- Белки: 20-30г (медленные, например казеин)
- Углеводы: 30-50г (средний GI, например овсянка, бурый рис)
- Жиры: 5-10г (минимум, чтобы не замедлять усвоение)

**Примеры**:
- Овсянка + протеин + немного орехов
- Гречка + курица
- Банан + творог

### 2. Интра-тренировочный приём (Intra-Workout)
**Время**: Во время тренировки  
**Цель**: Поддержание уровня гликогена, снижение катаболизма  
**Состав**:
- БCAA: 5-10г
- Электролиты: натрий, калий, магний
- Простые углеводы: 20-30г (малый GI, например cyclodextrin)

**Примечание**: Опционально, особенно для длительных тренировок (>90 мин)

### 3. Пост-тренировочный приём (Post-Workout)
**Время**: В течение 30-60 мин после тренировки  
**Цель**: Быстрое восстановление гликогена, запуск синтеза мышечного белка  
**Состав**:
- Белки: 25-40г (быстрые, например сывороточный протеин)
- Углеводы: 50-80г (высокий GI, например белый рис, банан, декстроза)
- Жиры: минимум (замедляют усвоение)

**Примеры**:
- Сывороточный протеин + банан + белый рис
- Протеиновый коктейль с декстрозой
- Творог + фрукты

### 4. Комплексный приём за 2 часа до тренировки
**Время**: За 2 часа до тренировки  
**Цель**: Подготовить систему к нагрузке  
**Состав**:
- Белки: 30-40г
- Углеводы: 50-70г
- Жиры: 10-15г

### 5. Комплексный приём после тренировки
**Время**: Через 2-3 часа после пост-тренировочного приёма  
**Цель**: Поддержать анаболизм, восстановить гликоген  
**Состав**:
- Белки: 30-40г
- Углеводы: 50-70г
- Жиры: 15-20г

**Примеры**:
- Гречка + индейка + овощи
- Рис + лосось + брокколи
- Макароны + курица + салат

## Тайминг по целям

### Для набора массы (Bulk)
- 5-6 приёмов в день
- Пред-трени: + углеводы
- Пост-трени: максимальные углеводы (80г+)

### Для сушки (Cut)
- 5 приёмов в день
- Пред-трени: умеренные углеводы
- Пост-трени: умеренные углеводы (50-60г)

### Для поддержания (Maintenance)
- 4-5 приёмов в день
- Сбалансированный подход
- Адаптация под уровень активности

## Фармако-пищевые правила

### Приём с едой (with_food)
- **17α-алкилированные препараты**: methand, oxan, stan, trena
- **Берберин**: с едой для снижения GI-побочек
- **Статины**: на ночь с едой
- **Метформин**: с едой для снижения побочек
- **Диклофенак/мелоксикам**: с едой для защиты ЖКТ

### Натощак (empty_stomach)
- **MK-677**: на ночь, за 30 мин до еды
- **CJC-1295**: натощак, за 1 ч до и 30 мин после
- **GHRP-6**: натощак, за 1 ч до и 30 мин после
- **BPC-157**: натощак, за 30 мин до

### С углеводами (carbs_required)
- **Инсулин**: обязательные углеводы (50-80г)
- **Кленбутерол**: с едой для защиты мышц

### С жирами (with_fats)
- **17α-оральники**: жиры для абсорбции (10-15г)
- **Анастрозол**: жиры для усвоения

### Ограничить калий (limit_potassium)
- **Телмисартан**: ограничить калий до 3г/день
- Исключить: бананы, картофель, шпинат, авокадо

### Добавить магний (extra_magnesium)
- **Кленбутерол**: магний 400мг, таурин 2г

## Дни отдыха

- Убираем пред-тренировочный приём
- Уменьшаем углеводы в пост-тренировочном приёме (до 30-40г)
- Адаптируем общую калорийность под уровень активности

## Важные моменты

1. **Гидратация**: Пейте воду до, во время и после тренировки
2. **Пептиды**:MK-677 на ночь натощак, BPC-157 за 30 мин до еды
3. **Инсулин**: Обязательные углеводы вокруг инъекции
4. **Калорийность**: Адаптируйте под цель (набор/сушка/поддержание)
5. **Регулярность**: 5-6 приёмов в день для оптимального анаболизма
