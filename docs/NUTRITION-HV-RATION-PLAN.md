# План: HV-рацион бодибилдера — типология приёмов + база (Sep 2026)

Требования пользователя (дословно, с вердиктами):
1. Завтрак: овсянка/рисовая манка 150 г сухого + протеин. Вердикт: да (утро = медленные).
2. Полдник: рисовая манка 150 + протеин 60. Вердикт: да (формат «крем + изолят»); порошок в коктейле поднять 30 → 60.
3. Обед: рис 120 сухого + мясо + углеводный десерт 30–60. Вердикт: да, десерт — новый слот (сахар-кап дня уважаем).
4. Перекус 2: хлопья 150 или аналог — ок; КОНСЕРВЫ ВОН ВООБЩЕ (не «бич-пакет»). Вердикт: canned-id вне автопулов, замена — tuna_steak/курица/индейка.
5. Хлопья с ужина → амилопектин/HBCD в пост-трен (peri-shift). Вердикт: да; закрывает висяк «пост-трен C0». Декстроза и так только peri (страж + дампы).
6. Все продукты — через кнопку сухой/готовый вес. Вердикт: см. weight-mode ниже.
7. Хлопья — plain (без сахара/пшеницы). Вердикт: текущий corn_flakes уже plain (аллергены [], GF, 80У) — новый id не нужен.

## Интернет-синтез (2025–2026)

- Крем риса (82У/100 сухого, 1 г клетчатки) — peri-топ №1: pre за 60–90 мин и post (быстро, без вздутия, мешается с сывороточным). Овсянка (66У + 10 клетчатки) — утро/фон.
- HBCD/циклодекстрин — intra+post (низкая осмолярность, без ЖКТ-реба; декстроза дешевле, но дует — ей место post, не intra). У нас уже так (intra = амилопектин).
- Pasta 90У/100 сухого, rice cakes (лёгкие, portable, перед треной), corn flakes double-serving + whey (mass-еда), пряники/джем/финики/мёд (плотные vehicles под сахар-капом).
- Вывод: добавить в БД `rice_semolina` (сухая), `rice_cakes`, `honey`. Остальное есть (cream_of_rice, corn_flakes, pryaniki, jam, dates, vitargo/cyclic_dextrin, orange_juice peri-only).

## Weight-mode (сухой/готовый)

Слой display-only (`planner-weight-mode.ts`): `foodState` + regex + `DRY_TO_COOKED`, математика не трогается.
- `rice_semolina`: `foodState: 'dry'`, паттерн `/rice/` (k=2.8) — из коробки.
- `honey`: ни под что не подходит → `'other'` — из коробки.
- `rice_cakes`: ЛОВУШКА — `/rice/` даст ×2.8, а хлебцы едят сухими. Guard в `dryKeyFor`: `/cake|crispbread|flake/` → null.
- Закупки (`toRawPurchaseAmount`) подхватят новые id через те же флаги.

## P0 — типология приёмов (движок, свои файлы)

- Завтрак: основа каша 120–150 сухого (oats_dry/rice_semolina), один гарнир + белок (рост вместо второго — уже есть).
- Полдник: манка 150 + протеин (порошок до 60 в снек-коктейлях).
- Обед: рис 120 сухого + мясо + слот «десерт» 30–60 (pryaniki/jam/dates/honey — только при сахарной комнате дня; в peri/presleep слот запрещён как раньше).
- Перекус 2: хлопья 150 + СВЕЖЕЕ мясо (tuna_steak/chicken/turkey); вето sweet+flesh уже стоит.
- Ужин: без хлопьев (мясо+овощи+жиры); доля углей → postw жидкими (peri-shift, в пределах postw-бюджета).
- Post-трен: амилопектин/HBCD к изоляту (закрывает C0), декстроза — только peri (страж цел).

## P1 — база и гейты (свои файлы + БД)

- NEW id: `rice_semolina` (~370 ккал, Б7/Ж1/У80, dry), `rice_cakes` (~380/82, baked-сухие), `honey` (~300/82У). Категории/аллергены/теги по образцу соседей; авто-деривацию FOOD_ALLERGEN_DIET проверить.
- Guard хлебцев в `dryKeyFor` (см. выше).
- Бан консервов: `tuna_canned` (+ прочие canned) — вне автопулов (buildFoodPools/ротации), в БД остаются для ручного. Ротация → `tuna_steak`.
- Порошок в коктейле: max 30 → 60 (снек/ultraP; SUPPLEMENT_MAX и так 60).

## P2 — доводка и контроль

- Плотностная маршрутизация: рис/крем раньше картофеля на HV (ведро 348) — в пределах капов семейств.
- Verify-тесты: типология ×5 приёмов, бан консервов (0 canned в автопланах), десерт в капе сахара, peri-shift без потери сходимости, weight-mode новых id (dry/raw суффиксы).
- Полный сьют IndividualPlan без новых красных (база: 11; половина — чужие recipe-зоны + граничные).
- Коммит строго pathspec своих; НЕ пушить (очередь чужих); APK собирается вручную.
