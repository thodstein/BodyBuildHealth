# Кардио-конструктор — полный аудит и план доработки (Aug 16 2026)

Статус: [ ] запланировано · [~] частично · [x] реализовано

## 1. Текущее состояние (факты)

### Код
- Движок `cardio.engine.ts` — 1156 строк (CardioCycle, фазы/делоды/taper+peak, phaseSplit,
  персонализация, авто-подстройка, история версий, качество цикла, .ics/печать/сводка).
- Дневник `cardio-diary.engine.ts` (178 строк), мост `cardio-bridge.ts` (44).
- Мастер `CardioConstructor.tsx` (515) + 13 UI-компонентов (~1700 строк):
  CardioUserCard, CardioParamsStep, CardioCompsStep, CardioPreviewStep, CardioManageStep,
  CardioDiaryStep, CardioDiaryPanel, CardioAutoTunePanel, CardioSessionTimer,
  CardioWeekEditor, CardioProgressCard, CardioVolumeChart, CardioLinkCard.
- Тесты: 6 движковых + 4 UI-файла, **144 теста** по кардио-области.

### Функциональность (что работает)
- Пошаговый мастер из 5 шагов (Параметры → Старты → Предпросмотр → Управление → Дневник).
- «Графа пользователя»: возраст/пол/вес/ЧСС покоя/уровень, «📋 Из профиля» / «💾 В профиль».
- Персонализация: уровень (×0.8/1/1.15), оборудование (6 видов, низкоударные), пол (ЧССмакс),
  возраст/ЧСС покоя (Karvonen-зоны сессий).
- Быстрые старты (5 пресетов), ручная структура фаз, конструктор taper (1-4 нед, пик вкл/выкл).
- Живой предпросмотр с валидацией; план по фазам; taper-план; график объёма; качество цикла (score);
  прогресс цикла (неделя/%/adherence/старт); расписание недель (развёрнуто).
- Библиотека карточками (активировать/копия/сравнить/.ics/печать/удалить), переименование,
  текстовую сводку в буфер.
- Дневник: запись сессий (RPE/ЧСС), статы 7/28, adherence, рекомендации (снизить/сохранить/увеличить),
  авто-режим (подстройка по ACWR/дневнику с diff и undo), таймер-сессии, история версий.
- Интеграция: CardioLinkCard в ПЛ-авто/ББ-авто/ручном, привязка к макроциклу (cardioCycleId,
  PL v7/BB v8), кардио-слой «Итог года».

## 3. План доработки

### Этап 1 (P0) — «💡 Почему такой план» + варианты
- [x] Движок: `cardioPlanVariants(goal, opts)` — 3 варианта (щадящий/базовый/интенсивный):
      метрики (мин/нед, ккал, HIIT-нед) + обоснование каждого;
      `explainCardioChoice(goal, level, daysAvailable, recoveryLow, equipment, lowImpact, comps)` —
      текстовое объяснение выбора (цель → профиль → оборудование → старты).
- [x] UI: на шаге «Предпросмотр» карточка «💡 Почему этот план» и «⇄ Варианты нагрузки»
      (щадящий/базовый/интенсивный → пересборка активного цикла).
- [x] Тесты: варианты, объяснение, переключение.

### Этап 2 (P0) — «🗓 Неделя по дням» в предпросмотре
- [x] В CardioPreviewStep: блок «Неделя по дням» (Пн–Вс) со степпером недели,
      сессии с оборудованием и ЧСС.
- [x] Тесты: дни недели в предпросмотре.

### Этап 3 (P1) — «✨ Улучшить цикл»
- [x] Движок: `improveCardioCycle(cycle, opts)` — авто-исправления:
      сушка/рекомпозиция без HIIT (если восстановление и дни позволяют) → HIIT на build/maintenance;
      рекомпозиция с малым объёмом → частота zone2 +1 на maintenance; список изменений.
- [x] UI: кнопка «✨ Улучшить» на шаге «Предпросмотр» с предпросмотром изменений
      и подтверждением (история версий — undo безопасен).
- [x] Тесты: исправления по категориям, идемпотентность, отсутствие мутаций.

### Этап 4 (P1) — Протокол сессии
- [x] Движок: `cardioSessionProtocol(session, zones?)` — фазы сессии
      (разминка/основная/заминка; HIIT — интервалы 30/90) с минутами и пульсом.
- [x] UI: в CardioSessionTimer показ фаз протокола и активной фазы по ходу таймера.
- [x] Тесты: протокол по типам, минимальная длительность.

### Этап 5 (P2) — Дни недели в редакторе сессий
- [x] CardioWeekEditor: у каждой сессии селект «день недели» (Авто/Пн-Вс);
      ручной день сохраняется в dayOfWeek и учитывается в раскладке.
- [x] Тесты: ручной день сохраняется.

### Этап 6 (P3) — Полировка
- [x] Пустые состояния шагов с CTA (старты/библиотека/сегодня);
- [x] aria-атрибуты для интерактивных элементов (степперы, селекты, кнопки);
- [x] Авто-режим: автоматический предпросмотр подстройки при изменении цикла/дневника
      (без применения — решение за пользователем).
- [x] **Фикс критического бага**: `cardioWeekForDate` без reference брал `new Date()`
      с временем → «Сегодня»/прогресс/таймер показывали пусто (неделя 0);
      теперь reference по умолчанию — локальная полночь.

## 4. Критерии готовности (после всех этапов)

- [x] Пользователь видит объяснение, почему выбран именно такой кардио-план, и может
      переключиться между вариантами нагрузки;
- [x] Недельный план отображается по дням (Пн-Вс) с оборудованием и целевым ЧСС;
- [x] «✨ Улучшить» применяет исправления по отчёту качества с подтверждением и undo;
- [x] Каждая сессия имеет протокол (разминка/основная/заминка) с пульс-шагами;
- [x] День недели сессии редактируется вручную;
- [x] Все шаги имеют понятные пустые состояния и aria-атрибуты;
- [x] tsc 0 по моим файлам, cardio-тесты зелёные (158), `vite build` OK.
