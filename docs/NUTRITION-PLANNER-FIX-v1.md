9. **Portable сквозной**: `isPortableFood/isWorkWindowMeal` переехали в `food-availability` (единая точка); гейты в HV-доборе, корректоре (swap + новый пункт) и ребалансе (топ-ап + оба swap); проводка из контекста (`_portableRebOpts`) и генерации рецептурного дня.

13. **Сетка времени**: уже из настроек (gapFill по разрывам: 7:00→~10:00→12:00; pre −90мин, post +30, presleep −30 от сна, смена сдвигает обед/ужин) — без правок, покрыто плотными бюджетами снеков.
