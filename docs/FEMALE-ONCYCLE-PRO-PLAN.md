## §1. Аудит покрытия (приложение «Женщины и ААС», 13 табов)

| Тема | Сейчас в приложении | Вердикт |
|------|---------------------|---------|
| **Железо/ферритин** | Только строка в лабах (`Ферритин 15–150`, без атлетических порогов), TSAT нет; протокола железа нет; симптомов дефицита нет | ❌ ГЭП (приоритет №1 по запросу) |
| **Аменорея/цикл** | Красный симптом «>3 мес → гинеколог-эндокринолог» + таймлайн «>6 мес» + менструальный дневник; нет дифдиагностики (FHA vs AAS-супрессия), нет обязательного теста беременности, нет лаб-панели | ⚠️ Частично |

| **Урогенитальное** (сухость/диспареуния/ИМП) | Ничего | ❌ ГЭП |
| **Гирсутизм-шкала** | Симптом с тактикой, без количественной шкалы | ⚠️ Частично |
| **Фертильность** | Таб + правило «ждать 1–3 мес», заморозка упомянута; AMH/резерв до курса — нет | ⚠️ Частично |
| **Лабы по фазе цикла** | «3–5 день цикла» в табе «Лабы» | ✅ Есть |
| **Голос/вирилизация** | Запись голоса, стоп-симптомы, Virilization Score | ✅ Есть |
| **Гематокрит/липиды/пролактин** | Женские пороги (в т.ч. движок `§16.3`) | ✅ Есть |

**Ключевой конфликт для железа:** ААС стимулируют эритропоэз (HCT↑), а железо — субстрат эритропоэза. На курсе железо можно грузить **только при подтверждённом дефиците и при HCT <48** (иначе — риск гипервязкости). Это правило должно быть жёстким гейтом.

## §2. Интернет-синтез (источники 2024–2026)

### 2.1 Железо (главный запрос)
- **AAFP 2025** (Iron Deficiency Anemia: Evaluation and Management): ферритин **<45 нг/мл** — дефицит при анемии; **46–99 + TSAT <20%** — дефицит без анемии; при воспалении порог <100; **дозирование через день** улучшает всасывание; контроль ответа через **2–4 недели**; при непереносимости/неответе — **в/в железо**.
- **Stoffel/Moretti** (Blood 2015; Am J Clin Nutr 2017): приём через день даёт **+33–50% фракционного всасывания** (гепсидин-механизм: доза ≥60 мг поднимает гепсидин на ~24 ч); дробление «утро+вечер» **не** увеличивает биоусвоение; оптимальны дозы **40–80 мг** элементарного железа утром натощак.
- **PMC10608302** (железо у атлетов): достаточный ферритин **>100 нг/мл**; функциональный дефицит **30–99**; абсолютный **<30**; для дефицитных атлетов **40–60 мг элементарного/сут**; у женщин-атлеток cutoff **30** (у мужчин 20).
- **BJSM 2025** (Dugan): у железодефицитных **неанемичных** тренирующихся женщин (ферритин **<20**, Hb норма) — в/в железо улучшает работоспособность; пероральное — при отсутствии ответа 4–8 нед.
- **Schulte PM&R 2024** (NCAA D1, женские легкоатлетки/футболистки): бисглицинат **3×/нед** достоверно поднимает ферритин при IDNA (альтернатива при непереносимости ежедневного).

### 2.2 Цикл / кости / RED-S
- **2025 Update Female Athlete Triad Coalition** (Sports Med 2026;56(2):375, Part 2): уход от порога энергодоступности; «primary indicators» высокого риска — **менструальные нарушения, низкий BMD, костные стресс-повреждения (BSI), РПП**; гипер-андрогенемия — конфандер при оценке аменореи; восстановление менструаций «один цикл ≠ норма» — нужны **последовательные нормальные циклы** (и овуляция восстанавливается позже).
- **ACOG (Healthy Female Athlete)**: низкий E2 → остеопороз и проблемы фертильности; кальций подросткам 1300 мг.
- **IOC REDs 2023** + PMC9724109: LEA → множественные системы; BSI-риск ↑ у аменорейных.
- **AFP 2026 / Endocrine Society 2017**: аменорея — обязательны **тест беременности** и **E2, FSH, LH, PRL, TТГ**; FHA лечится энергобалансом/весом; КОК при FHA **не улучшают BMD** (PMC9592968); BSI у аменорейных 28–47% против 17–25.6% у эуменорейных.
- Питание при риске Triad/REDs: кальций **1000–1500 мг** (при аменорее — к 1500), витамин D, Mg, Zn, K, белок **1.6–2.2 г/кг**.

### 2.3 Практические выводы
1. Железо — **только по анализам** (ферритин/TSAT/ОАК) и с гейтом по HCT.
2. Аменорея >3 мес — алгоритм, а не одна строка: беременности-тест → E2/FSH/LH/PRL/ТТГ → гинеколог; >6 мес или BSI — DXA (**z-score**, не T; z < −2 = ниже ожидаемого для возраста).
3. Кости — профилактика (Ca/D3/K2/Mg + силовой тренинг) + честное «КОК не чинят BMD».
4. RED-S — светофор по признакам (без EA-порогов, как в обновлении 2025).
5. Гирсутизм — количественная шкала Ferriman-Gallwey (9 зон) для динамики.
6. Урогенитальное на низком E2 — лубриканты/гигиена/локальный эстроген (врач).

## §3. Предложения

### P1 — контент протоколов (табы и шкалы)
1. **NEW таб «🩸 Железо и ферритин»**: диагностика (ОАК, ферритин, TSAT натощак, CRP при воспалении), атлетические пороги (<30 дефицит / 30–50 функциональный / >100 достаточно; TSAT <20%), схема (40–60 мг элементарного ежедневно **или** 60–100 мг через день — лучше всасывание; бисглицинат/сульфат; утро натощак + витамин C; разнос с кофе/чаем/кальцием/цинком ≥1–2 ч), контроль (ферритин/ретикулоциты через 4–8 нед; неответ → в/в, врач), **ГЕЙТ КУРСА**: HCT ≥48 — железо не грузить (сначала гемато-контроль); Hb <100 — к специалисту; не «на всякий случай» при нормальном ферритине.
2. **NEW таб «🦴 Цикл, кости, RED-S»**: тест беременности первым; панель E2/FSH/LH/PRL/ТТГ/Т3св/vit D/железо; аменорея >3 мес → врач, >6 мес/BSI → DXA (z-score); профилактика Ca 1000–1500 + D3 + K2 + Mg + белок 1.6–2.2; «КОК не улучшают BMD»; восстановление — последовательные циклы; RED-S-светофор (5–6 признаков: менструальные нарушения, BSI, потеря веса/РПП, низкий BMI, длительность дефицита, стресс).
3. **FG-шкала** (Ferriman-Gallwey, 9 зон 0–4, порог >8) в таб «Вирилизация» — динамика + фото-локусы.
4. **Урогенитальный блок** (сухость/диспареуния/рецидивы ИМП на низком E2: лубриканты, гигиена, D-манноза, локальный эстроген — врач) — в «Кости/цикл».
5. **Фертильность**: AMH + «оценить резерв до курса» + честная оговорка обратимости.
6. **Лабы**: `FEMALE_LAB_GROUPS` — ферритин с атлетическими порогами, добавить строку **TSAT (<20%)**.

### P2 — движок и авто-поддержка
7. **`female-support-layer`**: условное железо **только при наличии анализов** `labs.FERRITIN <30 && labs.HCT <48` (иначе тихо; мужской путь не меняется) + справочный BONE-набор (Ca/D3/K2/Mg) — проверить `CATEGORY_LIMITS` для mineral.
8. **`FEMALE_SUPPORT_PROTOCOLS`** += «Железо (по анализам)» и «Кости (Ca/D3/K2/Mg)» с дозировками и гейтами.
9. **Таймлайн**: шаг «аменорея >3 мес → тест беременности + E2/FSH/LH/PRL/ТТГ → гинеколог-эндокринолог».
10. **Статья `lab-guide-course`**: женский блок (железо/цикл/кости) + ссылка на табы.

### P3 — опционально
11. «Диспансер женщины на курсе» — месяц-чек-лист (цикл, ферритин/HCT, кости-риски, настроение/либидо) с персистом.

## §5. Границы и риски
- Дозы железа/кальция и решения по DXA/КОК/локальному эстрогену — **только врач**; приложение — скрининг/динамика/гейты.
- Не выдумывать EA-пороги (обновление Triad-2025 ушло от них) — светофор по primary indicators.
- В/в железо — только клиника; в авто-слой не попадает никогда.
- Ферритин при воспалении (CRP↑) завышен — оговорка обязательна.
