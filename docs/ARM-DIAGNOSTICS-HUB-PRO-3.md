## 1. Аудит хаба как есть (факты из кода)

### 1.1. Архитектура (ядро целое, ~30 движков)

Оркестратор `buildArmDiagnosticsReport` (hub.engine) собирает: weak-точки (12 `ARM_BIOMECH`) → причины (`weak-cause`: volume/technique/mobility/fatigue/strength) → топ-3 (`correction-rank`) → Δ-симуляция (`simulator`) → спец-блок 4–8 нед (`spec-block`) → инъекция во все недели + откат (`injection`, `he_arm_plan_saved_prev`) → мост (`bridge-payload`, kind `weakpoints` + R1-обогащение: причины/топ/spec/mobility/ACWR/bilateral/попытки/матчап/TIQ/профиль/RFD).

Покрыто хорошо: RSS-скоринг + floors + verification (оверлей, `scoreArm`), L/R-вердикт из 3 источников + bilateral-план с историей, VBT-пороги по точкам, матчап (стиль/рука/вес + «бей в …»), Table-IQ журнал + тренд, фолы WAF→чинить (памятка 5 фолов), red-flags скрининг + teen/beginner-press гейты, return-to-pull, мобильность 5 ROM + retest + →в профиль, per-muscle ACWR + tendon ACWR + авторегуляция + CNS, помост %WR + попытки 90/96/102 + журнал `he_arm_platform_log`, снапшоты `he_arm_measure_history`, аудит плана, экспорт HTML/CSV (XSS/BOM) + печать, сценарии (кап 6), персист v4 + P1 + TIQ.

## 2. Интернет-синтез (2023–2026, только проверяемое)

- **WAF Rules 2025 (офиц. PDF, waf-armwrestling.com):** Senior М — 11 категорий (−55…+110), Ж — 8 (−50…+90); L/R — отдельные зачёты; Masters/Sub-Junior/Junior/Youth — свои сетки. Фолы: отрыв локтя (любой, §8.3), плечо через центр (§8.1.2), «опасная позиция» плечо ниже подушки (§8.1.5–8.1.6), фол при проигрыше >2/3 пути = сразу поражение (§8.1.10). False start / referee's grip (§5.3, §7.1, §8.2): в судейском хвате то же движение = сразу фол; 30 с на «Grip Up». Лямки (§8.5): не ниже 2,5 см от запястья; намеренный срыв в проигрыше = фол + проигрыш. → Хаб: весогонка не привязана к классу; памятка фолов есть (5), но без связки «фол→конкретный дрилл» по всем пунктам §8; нет проверки старта/лямок как отдельных навыков.
- **Биомеханика hook + EMG:** Marotta et al., *Applied Sciences*, 2026 (11 hook-специалистов, sEMG): пронатор вырос ~30→127 мкВ за 10 сессий, доля бицепса −9 п.п. — hook = медиальный локоть под ударом (flexor-pronator перегруз → медиальный эпикондилит). Silva et al., *J. Electromyography & Kinesiology*, 2009: при 40% MVL самый активный — Pronator Teres; при 80% — PM + PT. POGTI Semarang, 2026 (Kinovea 0.9.5, 10 элитных): угол запястья 173°→91° (cupping-доминация), плечо стабильно 24–26 см («chain principle»). Toproll/press с гониометрическими нормами в рецензируемых 2023–2026: **данных не найдено**.
- **Скорость важнее пика:** Bezkorovainyi et al., 2023 (3 тяжеловеса 116±18 кг, стенд ARM2, 4 теста): временные характеристики (время до максимума, градиент, J-индекс) — **70,9% дисперсии**, макс. сила — 29,1%. → Хаб уже считает F/t/F100/F500/t05F — правильно; не хватает популяционных норм («что такое хороший F/t») и акцента на RFD в выдаче.
- **Травма №1 — спиральный перелом:** Ogawa et al., *JSES Reviews*, 2022 (153 пациента, 96% мужчины 15–34): 100% спиральные, 90% дистальная треть, парез лучевого 18,4% (все разрешились). Oh et al., 2024 (20 переломов): сращение ~14 нед; бьются в основном непрофи в равной/проигрышной позиции. Видеоанализ 74 переломов, SpringerMedicine 2024–2025: ротация туловища (p<0,001), сломанная ось «кисть–локоть–плечо» и запястье позади плеча — у 81,1%; 62,2% — в защитной позиции. → Практический маркер «broken arm position» = стоп-сигнал; хаб: humerus-guard есть, но без позиционного чек-листа и без per-week side-прогрессии ≤10% как явного правила.
- **Distal biceps — сроки есть, критериев нет:** Boufadel et al., *AJSM*, 2025 (1093 пациента): return-to-sport 91,5% за ~6,3 мес (атлеты 96,4% за ~9,4 мес). Консенсуса по объективным RTS-критериям нет (*JSES Int*, 2025): только время 8 нед–6 мес, без ROM/силовых порогов. Специфических return-to-pull критериев и красных флагов UCL с порогами: **не найдено** → честно оставляем return-to-pull как скрининг-лестницу, не «диагноз».
- **CoC — единственная шкала с числами:** IronMind/Rogue 2024–2026: Guide 60 … **№1 140, №2 195, №3 280, №4 365 фунтов**; сертификация только №3/3.5/4 (М) и №2/2.5 (Ж); №4 закрыли 6 человек. RT/Apollon — процедуры IronMind Contest Rules 2025 (оригинальная ручка, thumbless запрещён, локаут 1 с), фиксированных разрядных таблиц нет. Saxon 3″×4″ (Arnold Classic 2026, Armlifting USA) — живые лидерборды, не нормативы. Разрядных таблиц SAR: **не найдено** → честно: CoC остаётся ordinal + фунт-ориентир (как сейчас), Excalibur — классовая таблица без сведения к числу (как сейчас).
- **F/t и RFD — надёжность известна, норм для стола нет:** Čurović et al., *Muscles*, 2026 (Kinvent K-Grip, n=34): пик/mean ICC>0,97; поздние взрывные ICC 0,88–0,99; **ранний RFD ICC 0,67–0,88, CV 15–22%** — мерить только позднюю фазу. Порогов F/t и RFD для RT/pinch/CoC: **не найдено** → пороги хаба (ftIndex<30 и т.д.) маркируем как внутренние эвристики, не «нормы».
- **VBT для рук — норм нет:** Marques et al., *Sci. Reports*, 2025 (жим гор./накл., n=30): Нагрузка = 110,9−64,2×MPV (r²=0,96); 1ПМ приемлем только по 70–90% (CV<10%). Greig et al., *Sports Med.*, 2023 (мета-анализ LVP): ошибка ~4,3 кг с завышением; без тяжёлых точек врёт. Для пронации/супинации/бокового/кисти LVP-профилей: **не найдено** → VBT в хабе остаётся loss-зонами по своим порогам (честно), без претензии на 1ПМ-калибровку.
- **Supermatch-формат:** EVW Sports Rules 2025: **best-of-5 (до 3), титул best-of-7 (до 4)**; раунды 10–15 с, отдых ~60–90 с. Larratt, Fridman #265, 2022: «tower building», «never fail», 3–4 тяжёлых + blood-flow, спарринги-стол как метод. Тейпера/весогонки/table-time с цифрами для армрестлинга 2023–2026: **не найдено** → тейпер-пресеты хаба маркируем как переносимые (не «наука стола»).
- **ROM-эталоны локтя:** Zwerus et al., *Shoulder & Elbow*, 2017 (n=352): актив доминантной — **сгибание 146°, разгибание −2°, пронация 80°, супинация 87°**; М < Ж; **D/ND разница <1° — незначима**. Асимметрия хвата: Сингапур 2025 (n=500): доминант +6,2–6,9%, pinch +7–9,2%; HRS США 2023 (n=23056): >10% — 53%, >20% — 26%. Специфических порогов «годен/не годен» для стола: **не найдено** → пороги хаба 7/12% оставляем как рабочие эвристики с обоснованием (Bezkorovainyi + популяционный фон 6–9%).

## 3. План PRO-3 (эпики, все со своими тестами, движки/строки/aria 1-в-1 где не сказано)

### P1. VBT-двухзамерный флоу (закрывает G1+G2)
- Хаб Grip: второй набор полей (подход 1 / подход 2: вес + скорость) + хинт «сделай 2 подхода — loss считается между ними»; одиночный замер = только e1RM-оценка, без зоны.
- Движок: единый `vbtThresholdsFor` (weak-point таблица — канон, legacy `vbtForExercise` → депрекейт-алиас на неё); правило «запись без wp наследует первую выбранную точку» — явной строкой в UI, не молчаливой склейкой.
- Тесты: 1 замер → zone null + хинт; 2 замера → loss/зона; legacy-вызов → тот же порог, что канон.
- DoD: `arm-vbt-capture` + `arm-hub-tabs1` + тест; старых ассертов не ломаем (legacy-алиас держит).

### P2. Честный Force Vector + «нет данных» (закрывает G3+G4)
- `estimateForceVector`: totalScore считается только при ≥2 заполненных векторах, иначе `null` + подпись «введи минимум 2 замера»; одиночный 100 → не 100, а «недостаточно данных».
- `hub.engine`: без `actualPlan` — humerus/balance = `null` + честная строка «подключи план — оценка объёма недоступна» вместо mock-8-сетов; scoring без плана не ставит `sideSetsWeek1=8`.
- Тесты: 1 вектор → null; 2+ → среднее; без плана → humerus null + строка.
- DoD: `arm-force-capture` + `hub.engine` + `tabs1/pressure` строки + тест.

### P3. Нормы по классу: WAF-таблица «ты vs норма» (закрывает G5, частично)
Без выдуманных чисел — только то, что есть:
- NEW `arm-norms-table.engine.ts`: WAF-классы (Senior М11/Ж8, Masters, Junior/Youth — из WAF Rules 2025, статикой) + привязка: RT WR М/Ж (есть), Axle Apollon М/Ж (есть), Saxon-ориентир (есть), CoC фунт-ориентир (есть, ordinal), side/back %bw (есть, маркировать «внутренний ориентир, не норма WAF»), Excalibur — классовая строка без числа (как сейчас, честно).
- Хаб Grip: строка «твой класс: М-85 / норма RT … / ты …%» по введённому весу + полу; весогонка: «до границы класса N кг» (чистая арифметика, без методики сгонки).
- Тесты: класс по весу М/Ж; % от WR; граница класса.
- DoD: NEW движок + тест + `tabs1` norms-блок. SAR-таблиц не выдумываем (исследование: не найдены).

### P4. Red-flags в персист/экспорт/мост (закрывает G6)
- 5 чипов (боль/отёк/щелчки/онемение/перелом-подозрение) → `he_arm_diag_redflags` (кап 20, дата+текст) + строка в `HubOutput`/P0 + секция HTML/CSV экспорта + поле `armRedFlags` в bridge-payload (конструктор показывает стоп-баннер, сборку не ломаем).
- Стоп-правило явно: перелом-подозрение/онемение/острая боль = «стоп + к врачу» (скрининг, не диагноз — строка уже есть, дублируем в экспорт).
- Тесты: персист roundtrip; экспорт содержит секцию; payload несёт флаги; пусто → тишина (байт-в-байт).
- DoD: `panels` + NEW store-хелпер (или в существующий storage) + `export` + `bridge-payload` + тест.

### P5. Сценарии полные (закрывает G7)
- `he_arm_diag_scenarios`: расширить снимок до `fields+weakPoints+P1 (мобильность/боли)+TIQ-summary+матчап+попытки`; загрузка восстанавливает всё; старые снимки (только fields) — миграция с дефолтами, не краш.
- Тесты: save/load roundtrip полного снимка; load legacy → дефолты.
- DoD: `panels` (HubScenarios) + тест.

### P6. Дедуп точек + тихий срез (закрывает G8+G12)
- Выбор >3 точек: явный тост «взяты первые 3: …; остальные … — в следующий заход» (вместо молчаливого slice); legacy-зеркало показывает, какие именно legacy развернулись в какие 12.
- Инъекция: превью пишет «точка N — вне топ-3, не вставлена» строкой, а не молча.
- Тесты: 5 точек → тост + первые 3; инъекция-превью содержит «вне топ-3».
- DoD: `Hub` + `injection` превью-строка + тест. Поведение (первые 3) не меняем — только видимость.

### P7. Углы: честные «н/п» + side-финиш (закрывает G9)
- Точки с `angleJoint='none'`: бейдж «угол н/п — контроль по технике + видео» (уже частично) + ссылка «открыть видео-блок»; `phaseForArmAngle`: press + высокое значение → `side_pin` вариант (сейчас только `side_mid`) + строка «дожимание — вручную по видео».
- Тесты: side-н/п бейдж; press-high → side_pin.
- DoD: `biomechanics` + `tabs` бейдж + тест.
- **W5-фикс (честное отступление): движковая часть НЕ внедрена осознанно** — авто-хинт оставлен на `side_mid`: предлагать `side_pin` первым значило бы толкать пользователя в humerus-рискованное дожимание, в коде стоит safety-guard с комментарием + пинящий тест (`arm-biomechanics.test.ts:71-72`). Внедрена UI-часть: explainer «дожимание — только вручную по видео (авто-хинт даёт side_mid: side_pin humerus-рискован)» в Pressure-табе + UI-тест. Поведение безопаснее буквы плана.

### P8. Позиционный чек-лист humerus + side-прогрессия (интернет: Ogawa/Oh/SpringerMedicine + StrengthLog-якорь)
- NEW `arm-humerus-checklist.engine.ts` (чистый, без новых норм): 5 чеков перед тяжёлым столом — ось «кисть–локоть–плечо» цела / запястье не позади плеча / плечо не ушло внутрь-назад / локоть не едет / разминка сделана; любой «нет» → humerus warn + строка «broken arm position — стоп».
- Side-прогрессия ≤10%/нед — явной строкой в Pressure (сейчас только guard внутри); Table-week 3/2/1 — подпись «периодизация стола (Кузнецов VIII)», без претензии на новизну.
- Тесты: все «да» → ok; один «нет» → warn + стоп-строка; прогрессия-строка при росте >10%.
- DoD: NEW движок + `pressure` блок + тест. Возвратные сроки переломов (14 нед / 6,3 мес) — только в подсказке return-to-pull как ориентиры литературы, не как назначение.

### P9. RFD-акцент + пороги-маркировка (интернет: Bezkorovainyi 70,9% + Čurović ICC)
- Strength: блок F/t показывает RFD-градиент первым (время до максимума / J-индекс), пик кг — вторым; подпись «временные характеристики объясняют ~71% различий у элиты (Bezkorovainyi 2023)».
- Все пороги (ftIndex<30, F/t-зоны, VBT-зоны, 7/12% асимметрии) — подпись «внутренние эвристики хаба, популяционных норм для стола не опубликовано».
- Тесты: порядок RFD-первым; подпись присутствует.
- DoD: `tabs2` Strength + тест. Чисел не меняем.

### P10. Матчап + старт/лямки по WAF (интернет: WAF §5.3/§7.1/§8)
- Pressure TOP-блок: +2 дрилла — «старт без фальстарта» (судейский хват: плечо/кисть/пальцы неподвижны) и «лямки» (нейтральный слип → лямка 2,5 см от запястья, не срываться в проигрыше); связка с фолами §8 уже есть — дополнить маппингом «false start → дрилл старта», «намеренный срыв → дисциплина».
- Supermatch-пресет: best-of-5/7 + раунды 10–15 с / отдых 60–90 с — строкой в спарринг/sim-блоке (формат, не методика).
- Тесты: дриллы видны при выборе матчапа; формат-строка best-of-5/7.

## 4. Осознанно НЕ делаем (с причинами из исследования)

1. **CoC в кг** — фунт-рейтинг IronMind не калибруется в кг без RGC-измерения; остаётся ordinal + ориентир. Источник: IronMind Rules 2024.
2. **Популяционные F/t-нормы** — не опубликованы (Čurović даёт только надёжность, не нормы). Пороги хаба — эвристики с честной подписью.
3. **LVP-профили / 1ПМ по скорости для рук** — для пронации/бокового/кисти профилей нет (Greig: LVP врёт без тяжёлых точек). VBT остаётся loss-зонами.
4. **Тейпер/весогонка/table-time с цифрами** — публикаций для армрестлинга нет (Larratt — единственный первичный источник, без цифр). Пресеты — как переносимые, с подписью.
5. **SAR разрядные таблицы** — не найдены; Excalibur остаётся классовой строкой.
6. **Он-девайс видео-углы** — только ввод (JSON/Kinovea) + превью; live Hands — CDN, в APK офлайн-баннер (как сейчас).
7. **Диагнозы по травмам** — return-to-pull остаётся скрининг-лестницей (консенсуса по RTS-критериям нет, JSES Int 2025).
8. **Toproll/press гониометрические нормы** — в рецензируемых 2023–2026 не найдены; углы только для hook-кустов + общие ROM-эталоны локтя.
