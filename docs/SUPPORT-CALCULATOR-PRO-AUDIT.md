# Калькулятор поддержки — полный аудит и план доработок

**Дата:** 28 сентября 2026
**Область:** `src/engines/support-plan/`, `src/ui/screens/Calculator/`, `src/data/support-*`, `src/engines/tz-mapper-engine.ts`, `src/engines/tz-bridge-boosters.ts`, `src/engines/ped-risk-matrix.ts`, `src/engines/female-support-layer.ts`

## §1. Архитектура (текущее состояние)

```
UnifiedSettings (labs, pharma, health, lifestyle)
        │
        ▼
CalcMapper.tsx (UI, 4279 строк) ──► buildMapperCtx(state)
        │
        ▼
tz-mapper-engine.ts (resolvePlan) ──► SupportRecommendation
        │
        ├── tz-bridge-marker → getActivatedTzMechs(labs)
        ├── tz-bridge-phase → detectPhase / getPhaseProtocol
        ├── tz-bridge-mechanism → TZ_MECH_TO_SUBS, CATEGORY_LIMITS, TOTAL_LIMIT
        ├── ped-risk-matrix → assessPedRisk → tiers
        ├── tz-bridge-boosters → applyBoosters (neuro/joints/hemato)
        ├── female-support-layer → applyFemaleSupport [if female]
        ├── support-phase-labs.engine → addonsFor(phase, labs)
        ├── lab-priority-map → getPrioritySubstances
        ├── lab-tier-recommendations → computeTierAdjustments
        ├── lab-synergy-engine → computeSynergy
        ├── substance-contraindications → checkContraindications
        └── drug-interactions → checkInteractions
                │
                ▼
support-plan/engine.ts (calculateSupportTZ) ──► CalculatorResult
        │
        ├── engine-helpers.ts (titration, UL caps, schedule)
        ├── risk-engine-tz-spec (28 mechanisms × 6 systems)
        ├── SUPPLEMENTS_DB (371 substances → 28 mech IDs)
        ├── SUPPORT_DOSING (83 dosing records)
        └── PHARMACY_DB (pharmaceutical substances)
```

**Сильные стороны:**
- Единая точка входа `calculateSupportTZ` / `runSupportUnified`
- Каноническая система рисков TZ (28 механизмов × 6 органов)
- Многоуровневая система бустеров (LV1-LV3) с доказательной базой
- Фазовая система K0-K10 с лабораторными рекомендациями
- Женский слой с HCT-гейтом для железа
- Проверка взаимодействий и противопоказаний
- Титрация доз по весу с капом UL

## §2. Критические пробелы данных

### 2.1. Каталог веществ — покрытие 16% (КРИТИЧНО)

| База | Записей | С полным каталогом | Без каталога |
|------|---------|-------------------|-------------|
| SUPPLEMENTS_DB | 371 | **61 (16%)** | **310 (84%)** |
| SUPPORT_DOSING | 83 | 83 | — |
| SUPPORT_CATALOG_DATA | 61 | 61 | — |

**Следствие:** Калькулятор может рекомендовать 310 веществ, для которых UI не может показать:
- Формы выпуска (капсулы/таблетки/порошок/инъекции)
- Показания и механизмы действия
- Взаимодействия и противопоказания
- Побочные эффекты
- Мониторинг анализов
- Дозировки

**Наиболее критичные отсутствующие каталожные записи:**
- `creatine`, `omega3`, `magnesium`, `zinc`, `vitamin_c`, `vitamin_e`, `selenium`, `coq10` — базовые добавки
- `ashwagandha`, `curcumin`, `berberine`, `bacopa`, `rhodiola` — адаптогены
- `collagen`, `glucosamine`, `chondroitin`, `msm` — суставы
- `gaba`, `l_theanine`, `melatonin`, `glycine`, `taurine` — сон/нейро
- `iron`, `folate`, `vitamin_b12`, `vitamin_b6` — критично для женского слоя
- `nac`, `tudca`, `milk_thistle` — гепатопротекторы
- `nattokinase`, `serrapeptase`, `lumbrokinase` — фибринолитики

### 2.2. Дозировки — покрытие 22% (КРИТИЧНО)

304 из 371 вещества в SUPPLEMENTS_DB **не имеют записи в SUPPORT_DOSING**.

**Следствие:** Калькулятор не может предоставить дозировочные рекомендации для 84% рекомендуемых веществ. Пользователь видит вещество в плане, но без дозы.

**16 сиротных записей в SUPPORT_DOSING** (есть в дозировках, нет в SUPPLEMENTS_DB):
`amlodipine`, `atorvastatin`, `b_complex`, `clomiphene`, `doseRange`, `enclomiphene`, `enoxaparin`, `ezetimibe`, `glycyrrhizic_acid`, `iron_bisglycinate`, `ketosteril`, `metformin`, `red_yeast_rice`, `rosuvastatin`, `sam_e`, `sodium_bicarbonate`

### 2.3. Женский слой — 11 веществ (СРЕДНЕ)

| Категория | Вещества |
|-----------|----------|
| Общее улучшение (6) | vitex, inositol, folate, vitamin_b6, omega3, probiotics |
| Защита костей (4) | calcium, vitamin_d3, vitamin_k2, magnesium |
| Lab-gated (1) | iron_bisglycinate (только при ferritin <30 И HCT <48) |

**Пробелы:**
- `iron_bisglycinate` отсутствует в SUPPLEMENTS_DB (женский слой ссылается на несуществующее вещество)
- Нет каталожных записей для женских веществ
- Нет женских взаимодействий и синергий
- Ограниченное покрытие костей (нет collagen, boron)
- Нет женской специфичности для костного метаболизма (кальций + D3 + K2 + бор + коллаген)

### 2.4. Синергии — отсутствующие пары (НИЗКО)

| Отсутствующая синергия | Важность |
|----------------------|----------|
| ZMA (zinc + magnesium) | Высокая — базовая комбинация |
| creatine + beta_alanine | Высокая — спортивная |
| omega3 + vitamin_d3 | Средняя — абсорбция |
| collagen + vitamin_c | Средняя — синтез коллагена |
| NAC + TUDCA | Высокая — гепатопротекция |
| CoQ10 + PQQ | Средняя — митохондрии |

### 2.5. Эффекты на анализы — частичное покрытие (СРЕДНЕ)

Многие вещества не имеют маппинга на лабораторные маркеры:
- `creatine` → креатинин (ложное повышение)
- `gaba`, `melatonin`, `glycine`, `l_theanine` → нет эффектов
- Женские вещества (vitex, inositol) → нет эффектов
- `inferPharmaLabEffects` покрывает только несколько классов препаратов

## §3. Пробелы тестового покрытия

### 3.1. Модули без прямого тестирования

| Модуль/Функция | Статус | Риск |
|----------------|--------|------|

| `runSupportUnified` | Минимальный | НИЗКИЙ |

### 3.2. Критические пути без тестирования

| Путь | Риск | Почему важно |
|------|------|-------------|
| `resolvePlan` с фазой PCT | ВЫСОКИЙ | Постцикловая терапия — критичная фаза |
| `resolvePlan` с фазой bridge | СРЕДНИЙ | Мост между курсами |
| `resolvePlan` с фазой fertility | СРЕДНИЙ | Фертильность — специфичная фаза |
| `resolvePlan` с фазой TRT | СРЕДНИЙ | Заместительная терапия |
| `resolvePlan` с женским слоем + HCT-гейт | ВЫСОКИЙ | Железо при HCT≥48 опасно |
| `resolvePlan` с пустым/минимальным состоянием | СРЕДНИЙ | Защита от сбоев |
| `calculateSupportTZ` с различными PED-комбинациями | СРЕДНИЙ | Только test+tren+nand протестирован |
| `checkInteractions` с граничными случаями | СРЕДНИЙ | Пустые массивы, неизвестные вещества |
| `applyTitration` с неизвестными веществами | СРЕДНИЙ | Защита от сбоев |
| `normalizeDoseByWeight` с граничными весами | СРЕДНИЙ | 0, отрицательный, экстремальный вес |

### 3.3. Проблемы качества тестов

- Нет мутационного тестирования
- Нет source-guard'ов в e2e-тестах
- Нет негативных тестов (невалидные входы, ошибки)
- Нет тестов граничных значений (ровно на UL, на границах терапевтического окна)
- Использование `any` в тестах (`support-calc-e2e.test.ts:15`, `support-hub-pro.test.ts:44-45`)

## §8. Источники и обоснования
