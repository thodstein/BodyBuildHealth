## 2. Дефекты текущего блока

1. Нет карточек «до/на/после» — плоский список строк; baseline содержит одну гигантскую
   нечитаемую строку «Системные панели» + дублирующиеся мелкие строки.
2. PCT слаб: только нед 2 и 6, нет липидов/HCT/печени в PCT, нет ветвления по эфирам
   (короткие → SERM сразу; длинные → hCG-bridge 2–3 нед → SERM — есть только в PostCycle-протоколе).
3. Fertility тонкий: только «спермограмма + LH/FSH/TT/E2/PRL q6–8w» — нет ингибина B,
   WHO-границ, сроков восстановления 3–6 мес, правила «гормоны только OFF ≥6 нед/3 мес».
4. Bridge/TRT: bridge — одна строка q6w без HCT/E2; TRT q8–12w без PSA-правила
   (прирост >1.4 / абс. >4.0 → уролог) и HCT≥54-стопа.
5. Класс-специфика неполная: нет SARM-ветки (АЛТ/АСТ>100 → стоп, липиды, LH/FSH),
   DHT-ветки (DHT/PSA), MENT-ветки (E2+PRL усиленно), GLP-1-ветки (HbA1c q3m + липаза/почки),
   инсулин-K+ (гипокалиемия), клен-Mg (только K/Na/креатинин), T3-кость.
6. Преаналитики нет в карточке: washout биотина, 7 дней без тренировок перед АЛТ/АСТ/КФК,
   E2 чувствительный/середина недели, утро натощак.
7. Пороги местами расходятся с гайдами (PSA без правила прироста; eGFR без оговорки
   «креатинин у качков врёт → цистатин C»).
8. Три источника маркеров дрейфуют (LAB_MONITOR_DB ↔ SUBSTANCE ↔ catalog) — один и тот же
   телмисартан описан тремя разными строками.

## 3. Целевые карточки (формат: название · когда · перечень · цели · красные флаги · преаналитика; Rx — 👨‍⚕️)

- **K0. До курса (Baseline, 0 нед)**: ОАК+СОЭ; БХ (АЛТ/АСТ/ГГТ/ЩФ/билирубин общ+прям/альбумин/белок);
  липиды (ЛПНП/ЛПВП/ТГ/АпоВ/Лп(a)/hs-CRP); почки (креатинин + цистатин C + eGFR CKD-EPI +
  мочевина + мочевая + Na/K/Mg/Ca/фосфор); ОАМ + UACR; гормоны (TT утро натощак ×2 + FT/SHBG +
  LH/FSH + E2 чувств. + PRL + кортизол утро + ТТГ/fT3/fT4/АТ-ТПО); метаболизм
  (глюкоза/HbA1c/инсулин/HOMA-IR); ферритин/Fe/TSAT/D3/B12/фолат; коагулограмма
  (МНО/АЧТВ/фибриноген/D-димер); PSA ≥40 лет (или при ААС-анамнезе); АД/ЧСС/ЭКГ;
  УЗИ печени при плане оралов. Преаналитика: 7 дней без тяжелых тренировок; биотин-стоп
  (8 ч при ≤10 мг, 72 ч при мегадозах); утро натощак.
- **K1. На курсе — короткие эфиры/оралы (нед 2)**: АЛТ/АСТ (+КФК для разделения мышцы/печень;
  при <3×ULN → повтор через 10–14 дней без тренировок), ГГТ/билирубин при оралах
  (ALT>2×ULN → снизить/отменить орал), K/Na/Mg/креатинин при клене,
  креатинин/eGFR/UACR при трене.
- **K2. На курсе — контроль (нед 4, затем каждые 4 нед)**: ОАК (HCT/HGB), E2 чувств.
  (титрация AI; середина недели, 48 ч после инъекции), PRL (19-nor; подтверждение +
  макропролактин), АД/ЧСС, HCT+ферритин, липиды при дозе ≥500 мг/нед или оралах,
  глюкоза/HbA1c при GH (HbA1c q12w), глюкоза+K при инсулине, IGF-1 при GH q6–8w
  (цель — верх возрастной нормы), ТТГ/fT3/fT4 при T3/T4, K/Mg при клене,
  коагулограмма при фибринолитиках.
- **K3. Длинный курс (нед 8 и 12, далее каждые 12 нед)**: полный пересмотр
  (ОАК+БХ+липиды+гормоны+почки+ОАМ+коагулограмма) + УЗИ печени/простаты + ЭКГ + D-димер при HCT>52%.
- **K4. Мост (Bridge, каждые 6 нед)**: липиды + ОАК/HCT + АЛТ/АСТ + E2 + АД/ЧСС.
- **K5. TRT (после стабилизации, каждые 8–12 нед → ежегодно)**: TT (mid-normal) + HCT + PSA +
  E2 + липиды + АД; HCT≥54% → отмена/снижение/донация; PSA прирост >1.4 или >4.0 → уролог;
  HCT 48–50% на старте — обсудить риск до начала.
- **K6. Выход/PCT (нед 2 и 6 после отмены + 3 и 6 мес)**: нед 2 — LH/FSH/TT/E2/PRL
  (+липиды/ОАК/АЛТ/HCT); нед 6 — LH/FSH/TT/E2; 3 и 6 мес — повтор до восстановления;
  правило 24 нед (BJGP): T<8 + низкие гонадотропины → 12 нед → рост >2 → еще 8–12 нед →
  только потом эндокринолог. Ветвление: короткие эфиры → SERM сразу;
  длинные → hCG-bridge 2–3 нед → SERM. На курсе гормоны не сдавать; контроль — 6 нед после отмены.
- **K7. Фертильность (baseline + каждые 6–8 нед, оценка через 3–6 мес OFF)**: спермограмма
  по WHO-6 (объем ≥1.4, конц ≥16, total ≥39, прогрессивная ≥30%, морфология ≥4% —
  5-й перцентиль, не диагноз) + LH/FSH/TT/E2/PRL/SHBG + ингибин B; hCG/FSH-схемы только
  под врачом; криоконсервация до курса — опция.
- **K8. Экстренно**: HCT>0.60 / АД>160/100 / ЧСС>120 / боль в груди/одышка/ТГВ-симптомы /
  желтуха / олигурия+отеки / T>38.5+абсцесс / ALT>3×ULN + клиника → STOP + врач.
- **K9. Преаналитика и тайминг (отдельная карточка)**: биотин-washout, 7 дней без тренировок,
  утро натощак, E2-чувств./середина недели/48 ч, T — два утренних замера, повтор АЛТ<3×ULN
  через 10–14 дней, креатинин vs цистатин C, eGFR-оговорка NICE NG203.

## 7. Добивка: расширенные маркеры (исследование проведено, решение принято)

### 7.1. Гомоцистеин — ДА, нужен (главный гэп графика)

Доказательства прямые, на качков, а не общие:
- **Graham et al. BJSM 2006** (n=40, стаж >20 лет): Hcy значимо выше у текущих юзеров (SU)
  vs бросивших >3 мес (SA, p<0.05) и vs контролей-качков/сидячих (p<0.01); плюс HCT↑.
  Вывод: связка Hcy+HCT → повышенный риск тромбоэмболий у долгосрочных юзеров.
  Обратная корреляция SHBG↔Hcy (r=−0.828) — связь с половыми гормонами.
- **Ebenbichler et al. 2001**: build-up фаза (типичный массонаборный стек ААС) —
  11.9 vs 8.7 мкмоль/л у контролей (p<0.05); B12/фолат при этом не различались
  (т.е. дело не в диете, а в самих ААС).
- **Обзор 2024 (Balcer/Dolata)**: ААС нарушают всасывание B6/B12 → гипергомоцистеинемия
  как отдельный протромботический путь (наряду с ↑тромбоксана A2, фибриногена, факторов VIII/X).

Что у нас: инфраструктура ЕСТЬ (`lab-marker-map.ts:122` HOMOCYSTEINE + correctionIds
methylfolate/methylcobalamin/tmg/B6; стеки метилирования `support-stacks-part2.ts:902`;
OCR распознает Hcy), но **в `buildMonitoringSchedule` гомоцистеина НЕТ вообще** —
маркер висит без тайминга. Это и чиним.

Решение:
- Hcy: **K0 (baseline) + K3 (q8–12w на курсе) + K6 (PCT-контроль)**.
- Цели: <10 мкмоль/л — оптимум; 10–15 — коррекция B-триадой; >15 —
  гипергомоцистеинемия (триада + TMG 1000 + исключить дефицит B12/фолата, врач при клинике); >30 — срочно врач.
- Коррекция уже в каталоге (5-MTHF 400–800 + метилкобаламин 1000 + P5P 25–50 + TMG 1000) —
  связать маркер → назначение (как сделано для других маркеров через correctionIds).
- B12 + фолат — всегда парой к Hcy (причины ↑Hcy): B12 <200 пг/мл → коррекция;
  фолат низкий → methylfolate.

### 7.4. Вторая проверка: реальная практика (форумы, клиники, гайды по инъекциям)

Сверено с: VitalQuests pre-cycle panel (12 маркеров + дельта-правила), AnabolicPharm 3-panel
framework (pre 2–4 нед / mid 5–7 нед / post 4–6 нед + светофоры), NICE PH52 + QS23 (иглы/шприцы,
BBV), WHO 2022 consolidated key populations, Vermeulen 1999 (free-T), Rosner 2013 (E2 LC-MS/MS),
Melmed 2011 (PRL), Holick 2011 (D3), Greenland 2018 JACC (CAC).

**а) Подтверждено практикой — наш перечень полон по крови/БХ/липидам/гормонам.**
Канадский светофор (HCT 52/54; HDL 0.8/0.6; ALT 1.5×/3×; eGFR 90/75; E2 75–200 пмоль/л;
HbA1c 5.4/5.7; PRL <15/15–25/>25 нг/мл) совпадает с нашими порогами в пределах конверсии —
расхождений нет, только форма подачи (у нас текст, у них таблица green/watch/act —
берем их формат в карточки).

**б) Найдено 4 реальных пробела — добавляем карточки:**

- **K10. Инфекционный скрининг инъекционных (BBV)** — НЕТ у нас вообще, а по NICE/WHO
  это обязательный пакет для всех, кто колит: HIV + HBsAg/anti-HBs/anti-HCV в baseline (K0)
  и ежегодно; вакцинация HBV 3 дозы (0–1–6 мес); абсцесс/флегмона уже есть в urgent (K8) —
  оставить. Источники: NICE PH52 (тестирование HBV/HCV/HIV за 12 мес + вакцинация),
  WHO 2022 key populations, NICE QS23.
- **КАК (коронарный кальций)** — расширенная инструменталка: baseline в 40+ лет
  при стаже ААС >2 лет (Greenland 2018 JACC — CAC бьет калькуляторы риска); повтор по кардиологу.
  У нас есть ЭхоКГ/ЭКГ — КАК идет третьей строкой «расширенно».
- **DEXA (кость)** — при длинном AI-курсе / E2 в нуле / T3 длительно: DEXA раз в 1–2 года
  (уже есть в каталожной записи экземестана — поднять в карточку K2/K3 строкой).
- **Дельта-правила (взять из практики дословно, вместо абсолютных порогов там, где важна динамика):**
  HCT Δ>+5 п.п. от baseline → флеботомия; АЛТ >2× своего baseline → нагрузка оралов;
  HDL −40% от baseline → близко к зоне событий; TT −30% от baseline на 12-й нед PCT → стоп восстановления;
  E2 −30% от on-cycle steady-state → AI давит избыточно. Работают только при наличии K0 —
  еще один аргумент обязательности baseline.

**в) Точность назначений (преаналитика K9 — дополнить):**
- E2 — чувствительный LC-MS/MS, называть кодом (LabCorp 140244 / Quest 30289 / EU-эквивалент);
  стандартный иммуноанализ в мужском диапазоне врет на 50–100% (Rosner 2013).
- T на курсе — в trough (накануне следующей инъекции) для сравнимости между циклами.
- Free-T — Vermeulen из TT+SHBG+альбумин (альбумин уже в K0 — подписать его роль);
  при SHBG <15 или >80 — только прямое измерение (equilibrium dialysis).
- PRL baseline >20 нг/мл — аргумент против 19-nor + МРТ гипофиза (Melmed 2011).
- Электролиты: добавить Cl⁻/CO₂ к Na/K/Mg/Ca (CMP-стандарт, копейки).
- DHEA-S, эстрон — НЕ включаем (рутинных доказательств для ААС-мониторинга нет; DHEA-S
  максимум опционально при надпочечниковых вопросах — честно фиксируем отказ).

**г) Источник аддонов PCT/AI/DA:** в `pharma-db/` лежат только ААС/GH/пептиды/инсулин/клен/T3/GLP-1
(проверено grep: тамоксифен/кломифен/анастрозол/hCG — только ссылки в linkedSubstances,
реальных записей нет; они живут в support-каталоге + `LAB_MONITOR_DB` уже покрывает
anastro/cabergoline/tamoxifen). Значит `CLASS_LAB_ADDONS` строим из ДВУХ источников:
классы PHARMA_DB + ключи LAB_MONITOR_DB — это же заодно закрывает дедуп-дефект №8 из §2.

**Итог полноты:** после §7.1–7.4 перечень закрывает BJGP/NICE/WHO/Endocrine Society/практику
форумов и клиник без остатка, за исключением осознанных отказов (DHEA-S/эстрон в рутину,
NT-proBNP/тропонин вне симптомов, повтор Лп(a)). Дальше — только реализация по §5.

## 8. Раунд-9: границы унификации (зафиксировано, без churn в чужих файлах)

- **E2 20–40 vs 20–50.** Канон K-карт — 20–40 пг/мл (E2-протокол, каталог, FertilityPCT-экран,
  оба экспорта). В `symptom-solver.data-part*` (×20+) и `SYSTEM_PANELS.horm` живёт 20–50.
  Это допустимый верхний люфт (протокол лечит >60), а не ошибка — унификация потребовала бы
  правок 20+ чужих строк без медицинского выигрыша. Не трогаем, фиксируем границу.
- **MK-677: матрица vs канон.** `classifyPed('mk677') → 'gh'` (`ped-potency-table.ts:184`,
  верно — грелиновый миметик), но `detectActivePedClasses` (`ped-class-matrix.ts:195`)
  кладёт mk677 в sarm-корзину regex-ом. Следствие: пользователю MK-677 матрица показывает
  SARM-мониторинг (LFT/липиды/HPTA), а график/аддоны — GH-мониторинг (IGF-1/глюкоза).
  Вред низкий (LFT/липиды всё равно не лишние), правит владелец матрицы: убрать mk677
  из sarm-regex + добавить gh-бакет по id (сейчас gh-бакет смотрит только `pharma.ghIU/hasGH`).
  Наши `addonsFor`/`CLASS_LAB_ADDONS` уже маппят mk677→gh (lock-тест есть).
