## 1. Свежие источники (Sep 2026, добор к V3)

**Траектория / биомеханика:**
- Arauz et al. 2025, J Biomech (elite, 80% max + EMG + vGRF): **взятие —
  force-доминантно** (vGRF выше почти во всех фазах, 904 vs 843 Н в конце
  первой тяги, p<0.001, выше EMG biceps femoris), **рывок — velocity/technique-
  доминантно** (выше пик. скорость штанги, больше экскурсия плеча). Подтверждает
  IMTP-ноту хаба; нового действия не требует, но усиливает P2 ниже.
- PoinT GO 2026 (IMU 800 Гц, обзор): **path consistency index (PCI)** —
  элита >90, средние 75–89, новички 60–75; **L/R-асимметрия >2 см, персист 4+
  нед → травмы ×1.7**; допуски AP: присед ±3, тяга J-curve ±4, **clean scoop
  ±5 см**; воббл 5 см → −0.05–0.08 м/с (−8–12%). Вывод: хабу не хватает
  **консистентности повторений** (один xLoop ни о чём) и **порога персиста**
  (одна асимметрия ≠ сигнал).
- Tunçel et al. 2025 (ЧМ-2010, Ariel): **Hmax растёт с весовой категорией**,
  LWC — выше относительная мощность второй тяги; **низкий Hmax + высокая
  мощность второй тяги = маркер успеха**. Вывод: yMax хаба сравнивать с нормой
  по весовой, а не абсолютом.
- Slobozhanskyi 2025, female 52 чел (Dartfish, 60% max): квалификация видна
  цифрами — **финал. ускорение 1.10→0.89 с**, таз в амортизации 93→137°,
  колено в подседе 126→75°. Вывод: **нормы по уровню** для женского рывка —
  кандидат в биомех-таблицу (сейчас одна норма на всех).
- Heliyon 2024, ACL в dip толчка (кейс 148 кг, 210 кг, SIMI + AnyBody):
  **внутр. ротация колена 46.9° + tibial anterior translation +0.76 м/с**,
  квадрицепс/икроножная переактивны, hamstring/soleus недостаточны.
  Вывод: dip-блок хаба (см/мс) без **ACL-флагов** (вальгус + ротация +
  hamstring-дефицит) — пробел безопасности.
- JOSSI 2026 (нарративный обзор): перформанс + риск — только **интегрированно**
  (механика + ткани + переносимость), универсальных техмоделей нет,
  измерение скорости/силы на высоких скоростях ограничено. Подтверждает
  verification-рамку хаба; нового движка не требует.

**Изометрия (сходится, 2024–2025):**
- Lum et al. 2025, JSES (сборная, 16 нед): **IFP и IMTP PF коррелируют с
  мощностью рывка/взятия r=0.95–0.99 стабильно 16 нед**; ранняя сила
  Force50/200 + RFD0-200/250 → r=0.75–0.87. Вывод: **первая тяга (IFP/IPSP) —
  равноправный тест**, хаб держит только mid-thigh.
- Rochau et al. 2024 (студенты): **IPSP чуть сильнее коррелирует с суммой,
  чем IMTP**, особенно аллометрически; IMTP даёт больший абсолютный пик.
  Вывод: держать **оба протокола** (IMTP — макс. сила, IPSP — сила с пола),
  использовать по назначению, а не «или-или».
- Wang et al. 2025: портативные платформы валидны по PF (<5%), **RFD между
  девайсами несопоставим → смотреть импульс**. Усиливает серую зону RFD хаба:
  добавить **impulse** как переносимую метрику.
- Grover et al. 2024, PeerJ: **10×5с IMTP (10с отдых) надёжен и для PF
  (ICC 0.94), и для strength-endurance (ICC 0.79–0.81)**; 60с-протокол —
  ненадёжен. Вывод: **протокол выносливости силы** — готовый кандидат
  (10 повторов, дроп первый→последний).

**VBT / LVP (теория устоялась):**
- Swinton 2026 (SportRxiv, n=46): **multilevel MVT надёжнее индивидуального
  (TE 0.020 vs 0.048 м/с), SEE 1РМ 4.5 vs 9.5 кг**;个别 MVT переобучается на
  малом числе точек. Вывод: индивидуальный MVT хаба честен, но **нестабилен
  на 3 точках** — нужен shrinkage к популяционному (частичный пулинг) +
  честный TE в UI.
- Thompson / Weakley / Guppy 2024 (обзоры): **SDD средней скорости приседа
  ±0.06–0.08 м/с** — меньше = шум; **2-point метод** (45% + 85%) валиден для
  верха, для низа хуже; **mean vs peak путать нельзя**; баллистика vs
  не-баллистика (тормозная фаза занижает лёгкие веса → брать ballistic-
  counterpart до 50–60%). Вывод: хабу не хватает **SDD-гейта** (тренд
  0.03 м/с ≠ прогресс), **флага mean/peak** и **баллистик-оговорки**.
- PoinT GO MVT-гайд (González-Badillo): MVT специфичен движению, стабилен
  по уровню (меняется нагрузка, не скорость), **перетест после блока 4+ нед
  / ΔBW 3+ кг / layoff 3+ нед**. Вывод: в хаб — **напоминание о перетесте**,
  сейчас профиль «вечный».

**Стратегия старта (практика + цифры):**
- Nature Sci Rep 2024 (ЧМ 2011–2023, 3144 попыток): **успех падает 1→3**,
  медали решаются **2-й и 3-й**; опенер — самый успешный. Euro-2024 (170 М):
  **рывок 52% vs взятие 47%**, опенер выше всех. Catalyst/опыт: **опенер
  92–94%**, прыжки 3–5% (рывок 2–3 кг), разминка каждые ~3 попытки.
  Вывод: заявки 90/96/102 хаба — механика без **стратегии** (нет bomb-out
  гарда, прыжков по самочувствию, тайминга разминки).
- Sinclair: IWF обновляет каждые 4 года; **2025–2028 — current**
  (дефолт хаба верен), но источники расходятся в константах (A/b), а USAW
  уходит на **Q-points**. Вывод: зафиксировать канон + цикл в экспорте,
  Q-points — кандидатом (не обязательно).

  Хаб: PCI-бейдж в Видео + строка персиста в асимметрии; экспорт-нота.
  Тесты 4 (PCI-границы, персист 4+, разовый замер молчит, пусто → null).
- **V2 Две изометрии + импульс (G2+G3).** MOD `ta-imtp.engine` (без ломки):
  опциональные `ifpPeakN` (первая тяга) + `impulseNs` → `ifpRatio = IFP/IMTP`
  (норма ~0.5–0.55 по Rochau/Joffe пропорции; ниже = «слабо с пола»),
  impulse — переносимая метрика (приоритет над RFD при смене девайса).
  Хаб: 2 опциональных поля + строка «сила с пола vs power-позиция».
  Тесты 4 (ratio low/ok, impulse приоритет в тексте, пусто → null, старые целы).
- **V3 Честный MVT-2 (G5+G6+G7+G11).** MOD `ta-mvt.engine` + хаб:
  shrinkage MVT к популяционному при <4 точках (частичный пулинг,
  честный TE в UI: «MVT ≈ X ± 0.03 (мало точек)»), SDD-гейт тренда
  (±0.06: меньше = «в пределах шума»), флаг mean/peak у полей скорости,
  баллистик-нота лёгким весам, напоминание «перетести после блока 4+ нед /
  ΔBW 3 кг». Тесты 5 (shrinkage сужает TE, SDD молчит/сигналит, mean/peak
  флаг, напоминание рендерится).
- **V4 Dip-ACL гард (G8, safety).** NEW `ta-jerk-safety.engine.ts`:
  `jerkAclFlags({valgus, rotation, hamDeficit, dipDepth})` → warn/stop
  (ротация/вальгус + hamstring-дефицит из IMTP-профиля = «проверь технику,
  не диагноз»). Хаб: 2 чекбокса (вальгус/ротация) в толчке + связка с
  strength_deficit; экспорт-нота. Тесты 3 (stop при паре флагов, warn при

- **V5 Стратегия старта (G10).** NEW `ta-meet-strategy.engine.ts`:

  (опener + прыжки + гард). Тесты 4 (опенер-коридор, прыжки по движению,

- **V6 Нормы yMax + женские уровни (G9+G12).** MOD `biomechanics`/`barpath`

  ±8°) + ввод факта `data-wl="fem-fact"` (♀-ветка рывка) + `data-wl="fem-verdict"`

  Ж `T×306.54/(266.50−19.44·b⁻²+18.61·b²)`, флоры 50/41кг; хаб — строка
