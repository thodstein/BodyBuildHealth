# Нормы анализов: один источник чисел

Контракт для правок порогов, ступеней и женских зон. Пока он соблюдается, одно и
то же событие (АЛТ 120, HCT 53, креатинин 100) читается одинаково в калькуляторе
поддержки, таблице мониторинга, печати врача, уведомлениях и риск-модели.

## 1. Где живут числа

Всё начинается в `src/engines/lab-norms.engine.ts`. Других источников нет:

| Что | Экспорт | Значение |
|---|---|---|
| ВГН маркера по полу | `getLabNorm(code, sex)` | из `LAB_REFERENCES_*` |
| Женские границы | `FEMALE_LAB_BOUNDS` | ♀ АЛТ/АСТ/ГГТ 31, креатинин 97, HCT 48, HGB 150 |
| Гематокрит | `HCT_THRESHOLDS` | ♂ 51/54, ♀ 48/52 (`erythrocytosis`/`block`) |
| Гемоглобин | `HGB_THRESHOLDS` | ♂ 170/185, ♀ 150/165 (`upper`/`block`) |
| Печёночные ступени | `LFT_ULN`, `LFT_STAGES`, `LFT_STAGE_ULN`, `LFT_SIGNAL_ULN` | 1×/2×/3×/5×ВГН: ♂ 80/120/200, ♀ 62/93/155; сигнал ♂ 100 / ♀ 78 |
| ГГТ | `GGT_ULN`, `GGT_STAGE_ULN` | ♂ 55/110/165, ♀ 31/62/93 |
| Креатинин | `CREATININE_ULN` | ♂ 110 / ♀ 97 |
| Женские гормоны (текст) | `FEMALE_HORMONE_BANDS` | E2 40–200 (фолл.) / 70–500 (лют.), PRL 100–500 |
| Женские гормоны (числа) | `FEMALE_HORMONE_ULN` | E2 30/400/800, PRL 800/1500 |
| Формулировки | `lftUlnText(code)`, `labUlnText(code)` | «♂ <40 / ♀ <31», «♂ <110 / ♀ <97» |

## 2. Правила

1. **Одно действие — одно число.** Ступень называется действием (`reduce` —
   снизить/пересмотреть, `stopOral` — отмена оралов, `stopAll` — отмена всего), а
   не числом. Число берётся из резолвера, не пишется литералом.
2. **ВГН своего пола.** У женщины 31, а не 40; ступени считаются от её ВГН, поэтому
   ♀ «3×ВГН» = 93, а не 120.
3. **Верхняя граница выше UL — рядом предел.** Если цель печатается выше верхней
   нормы, рядом стоит порог действия («АЛТ 31–62 — повторить, >62 — пересмотреть»).
4. **Женский порог рядом с мужским** в любом справочнике (карточки K0–K10, таблица
   «Анализы», `monitoringSchedule`, каталог): «♂ <170 / ♀ <150 г/л», а не «<170».
   Исключение — специализированный женский блок (таб «Женщины и ААС»).
5. **Печать — для пациента.** В `ProtocolExport` женский протокол показывает только
   её половину двуполой цели (`patientSexText`); справочники показывают обе.
6. **Один перечень анализов** — карточки фаз K0–K10 (`support-phase-labs.engine`).
   График фазы (`monitoringSchedule`) в UI и печати не печатается: из него берётся
   секция `daily`. «Мониторинг», «Врачебный протокол» и K0–K10 — один контент.
7. **Индексы — в долях ВГН пациента**, а не от мужского знаменателя
   (`interpretLabs`: печень `/ВГН АЛТ`, почки `/ВГН креатинина`).
8. **Без `sex` — мужской путь байт-в-байт.** Новый параметр всегда опционален;
   существующие вызовы не меняют поведение.

## 3. Кто читает что

- `risk-engine-tz-spec` — механизм-ориентированная модель риска (главная):
  `HCT_THRESHOLDS`, `LFT_*`, `GGT_*`, `CREATININE_ULN` в `clinicalFloorsForLabs` и
  `getMiFromLab`.
- `risk-verification.engine` — маркеры верификации и флоры: HCT/HGB/АЛТ/АСТ/ГГТ
  держат те же ступени, что резолвер (один ряд на маркер во всех механизмах).
- `risk-engine-v7-matrix` / `lab-tier-ranges` — тиры 0–3 и референсы (`deriveTier(marker, value, sex)`).
- `lab-analysis.engine` — `interpretLabs(labs, sex)` и композитные индексы.
- `support-phase-labs.engine` — карточки K0–K10 (цели `T_HCT`/`T_HGB`/`T_E2`/`T_PRL`).
- `tz-mapper-engine` — `monitoringSchedule` (цели `MON_*`) и фарм-примечания.
- `ProtocolExport`, `CalcSystemPanel`, `Calc.mapper`, `notification-engine` — печать,
  панели систем и уведомления.
- `supportProtocolWomenData` — женский таб (зоны от резолвера и бэндов).
- `UnifiedSynergyCalculator` (`LAB_MONITOR_DB`) — таблица целей по препаратам.
- `substance-monitoring-db` — мониторинг по веществам поддержки.

## 4. Что ещё не сведено

- `LabsTzRiskTab` не смонтирован в `LabsScreen` (живёт только в тестах): литерал
  `PRL 100-500` и тиры `>250/>400`.
- `risk-verification`: ряды `RBC` (♂ 5.5/6.0/6.5, ♀ 5.2/5.6/6.0) и `BIL` — мужские
  литералы без резолвера.
- Мужские цели E2 в разделах фертильности/ГЗТ (`FertilityPCTScreen`) подписаны
  `♂`, но сами протоколы остаются мужскими по замыслу — женских веток там нет.
