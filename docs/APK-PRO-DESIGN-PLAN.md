# APK PRO-DESIGN PLAN — новый топовый вид и навигация каждого блока

> Статус: план утверждён пользователем (Sep 2026). Реализация — волнами, каждая волна = тесты + tsc 0 + коммит строго pathspec.
> Жалоба-основание: «сейчас всё так же блекло как в ТГ версии» — блоки рендерят TG-разметку, CSS лишь припудривает.
> Требование: **каждый блок, абсолютно всё — в новом топовом виде**, а не только навигация.

## 0. Три правила (нарушение = откат волны)

1. **Hero intact** — картинки/исходники не меняются, только подача поверх.
2. **TG/web 1-в-1** — любой TSX-правка shared-компонента только за `isNativeApp()`-гейтом; весь CSS строго под `html.app-native`.
3. **Гарды**: `apk-top-pack` (изоляция, hero intact, hex только в var-определениях), platform-branching тесты экранов, contrast-guard.

## 1. ВИЗУАЛЬНЫЙ ЯЗЫК «PRO» (единый для всех блоков)

### 1.1 Поверхности и глубина
- Фон: глубокий navy `#050b16` + 2 радиальных подсветки от акцента (сверху) и accent-2 (снизу), AMOLED `#000000`, light `#eef2f6`.
- Карточки: стекло — `blur(20px)`, фон `rgba(16,31,54,0.72)`, бордер `1px rgba(140,190,255,0.14)`, радиус 18–28, тень `0 8px 32px rgba(0,0,0,0.45)`, верхний блик `inset 0 1px 0 rgba(255,255,255,0.05)`.
- Иерархия: базовая карточка → elevated (больше тень) → hero-карточка (градиентная кромка). Плоских серых плашек не остаётся.
- Кромки смысла: левая 3px-полоса цветом статуса (акцент/успех/ворнинг/опасность), топ-полоса 2px у hero-блоков.

### 1.2 Цвет
- Бренд = динамический акцент (лайм/минт/небо/фиолет/янтарь/системный): `var(--accent)`, `--accent-rgb`, `--accent-2`, `--accent-contrast` (текст на акценте).
- Кнопка primary: градиент `accent → accent-2`, текст `accent-contrast`, glow `rgba(accent-rgb, 0.35)`.
- Семантика не перекрашивается: успех `#22c55e`, ворнинг `#f59e0b`, опасность `#ef4444`, инфо `#38bdf8`, медицина (давление/ЧСС/анализы) — свои цвета.
- Блоки различаются hero-артом и иконографией, а не радугой: один акцент на всё приложение.

### 1.3 Типографика
- Шкала: display 30/900/-1px (заголовки hero), title 15-20/800, body 13-14, caption 10-11/700 uppercase +0.5px.
- Все цифры (веса, ккал, повторения, деньги): `tabular-nums`, вес 800, крупный кегль для ключевых метрик.
- Контраст: основной текст `#fff`/`#f4f7ff`, вторичный — белый 55–72%, никаких серых на сером ниже WCAG AA.

### 1.4 Иконки
- Хром интерфейса (табы, тайлы, кнопки, хедеры): только штриховые SVG 24×24, stroke 1.8–2, round, `currentColor`. Эмодзи из хрома убраны.
- Размер иконок hero/тайлов 30–34px, цвет — акцент с `drop-shadow(accent, 0.35)`.
- Эмодзи остаются только внутри контента (дневниковые иконки типов, статусы) — там они данные, а не оформление.

### 1.5 Hero каждого блока (единый паттерн)
- Арт на всю ширину сверху без кропа важного (contain/top там, где важна картинка целиком; cover + кинематографичный shade там, где фон).
- Поверх: живые статы (3–4 метрики из данных, не заглушки) + одна primary CTA.
- Подложка под текст: градиент `28% → 2% → 55% → 96%` (верх читаем, низ глухой под кнопки).

### 1.6 Состояния (в каждом блоке, без исключений)
- Пусто: `NativeEmpty`-паттерн — большая иконка, заголовок, объяснение, CTA-кнопка действия (не «нет данных»).
- Загрузка: skeleton-блоки в геометрии будущего контента, не спиннер на пустом экране.
- Заполнено/пусто: визуальное различие (акцентная кромка + свечение vs приглушение + пунктир — паттерн `data-filled`).
- Stale/просрочка: янтарно-красная шкала «N дн. назад».
- Ошибка: карточка с retry, а не тост в никуда.

### 1.7 Motion (только APK, с уважением к reduced-motion)
- Вход экрана 0.38s, каскад списков (stagger 60ms), появление снизу-вверх 0.3s.
- Press: кнопки 0.97, тайлы 0.94, чипы 0.94.
- Свайпы между сабтабами, hero-drift только там, где cover-фон.
- Скелетоны shimmer, никаких резких появлений.

### 1.8 Навигационный хром (единый)
- Нижний таб: floating pill, active-таб в акценте с glow, бейджи-дотики, живые бейджи (вода в очереди и т.п.).
- Sub-header внутри блока: back + титул + контекстные действия; sticky-фильтры и поиск.
- FAB speed-dial (вода/тренировка/запись) — глобальный, не дублировать по экранам.
- Пустые экраны и модалки: bottom-sheet подача, свайп-закрытие, focus-visible кольца в акценте.

## 2. БЛОКИ: что именно станет новым

### 2.1 Главная — витрина
- Hero целиком + живая сводка дня (тренировка сегодня / ккал факт-план / сон) glass-блоком поверх.
- Умная CTA «Продолжить» (недоделанное: сессия, день питания, пропуск дневника).
- Свайп-карусель разделов (snap-ряд иконок 7 табов) вместо простыни; 3 SVG-тайла остаются.
- Пилюля виджет-очереди на Главной.

### 2.2 Тренинг (самый перегруженный)
- Hub-and-spoke: корень — 5 зон hero-карточками с бейджами (активный цикл, нед N, ACWR-зона); внутри зоны свой sub-header с back.
- Hero: карточка «тренировка сегодня» (упражнения/тоннаж/старт) вместо статистики ради статистики.
- Player: полноэкранный режим подходов (крупные цифры, свайп сетов, rest-таймер оверлеем, wake lock).
- Хабы/диагностики: единый язык (полоса секции + gauge + топ-3 + CTA «в план»), сейчас каждый выглядит по-своему.

### 2.3 Питание
- 3 корня: Сегодня (таймлайн приёмов утро→ночь) / План / Каталог; sticky-поиск и чипы в каталоге.
- Hero: кольцо калорий + БЖУ-бары живьём из дневника.
- Сканер штрихкодов — кнопкой в шапке «Сегодня»; напоминания о приёмах; виджет КБЖУ.

### 2.4 Анализы
- Строка маркера → tap открывает динамику (отдельный шаг с графиком и нормой).
- Hero: светофор панелей + «пересдать до даты».
- Напоминание о пересдаче, ICS-экспорт, офлайн последние результаты.

### 2.5 Риски
- Карта систем (тап по системе → её риски), общий gauge + топ-3 драйвера в hero.
- Share-репорт врачу кнопкой из hero; critical-бейдж в навбар.

### 2.6 Фарма (курс)
- Календарь: Курс → Неделя (таймлайн по дням) → Препарат (hero-карточка).
- Hero «сегодня по курсу» с чекбоксами; пуши расписания; виджет; биометрия на раздел.

### 2.7 БАДы/Поддержка
- Мастер «Собрать стек» отдельным native-flow (цель → курс → ограничения → стек).
- Hero «стек на сегодня» (утро/день/вечер); пуши приёмов; виджет.

### 2.8 Профиль
- Шапка с completeness + «заполнить пробелы» (прыжок к первому пустому).
- Единый экран «Сегодня» (все дневники одним чек-листом).
- §4.4: живое превью темы/акцента по тапу на свотч.
- «Телефон · APK» хаб: биометрия, бэкап, виджеты, QS, локали.

### 2.9 Статьи / Магазин / вторичные
- Статьи: чипы категорий + поиск + офлайн-кэш.
- Магазин: сетка с фильтрами (полный корзинный флоу — после MVP).
- Fertility/PCT, Peptides, Recovery, Reports, Gamification, SmartAssistant, Performance, PredictiveAnalytics, Plan, RoleManagement, Substances, SupplementClinic: минимум hero-stats + карточки-разделы (паттерн hubs). Порядок — по частоте использования.

## 3. СКВОЗНЫЕ СЛОИ

1. **Kit-компоненты**: `NativeHero` / `NativeSection` / `NativeTile` / `NativeStats` / `NativeCta` — убить копипасту CSS между блоками.
2. **Уведомления**: матрица что/когда/частота по 3 каналам (тренировки, питание, курс, анализы) — иначе спам.
3. **A11y**: TalkBack-имена всем новым SVG/кнопкам, контрасты, тач 44px.
4. **Темы**: каждая волна проверяется в тёмной + AMOLED + светлой × 5 акцентов.
