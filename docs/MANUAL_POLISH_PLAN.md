> до уровня ПЛ/ББ-трасс по удобству и визуалу. Структурная часть (3 трассы) готова.

- [ ] Довести до читаемого формата (как SRCBBScreen: «NxRxWкг»), добавить метрики дня если нет.

## M2 — Циклы: макроцикл
- [ ] Проверить макроцикл-чарт (объём/интенсивность по неделям, фазы, навигация по неделям).
- [ ] Доработать если нужно (фазовые подписи, клик по неделе → детали).

## M3 — Программы
- [ ] Проверить ProgramsTab в ручном режиме (фильтры, выбор, добавить в «Мои»).

## M4 — Методики

## M5 — Мои (MyTraining)

## M6 — Ручной калькулятор (programcalc)
