### 1.3. Сильные стороны
- Полный цикл «собрал → спланировал → выполняю → корректирую» с undo на каждом шаге.
- Объяснимость: rationale, «почему этот план», отчёт качества с действиями.
- Безопасность: подтверждение всех авто-изменений, история версий (cap 5), идемпотентность.

### 1.4. Слабые места и пробелы (против ПЛ/ББ-авто)
| # | Проблема | Критичность |
|---|----------|-------------|
| 1 | **Авто-режим не применяется автоматически** — только предпросмотр (по соображениям безопасности); нет опционального «применять с undo» | P1 |
| 2 | **Пропуск/перенос сессии** в исполнении: таймер не позволяет пометить сессию пропущенной (completed:false) — adherence считает только выполненные | P1 |
| 3 | **Печать не содержит «неделю по дням»** — только недели списком | P2 |
| 4 | **CardioLinkCard не показывает «Сегодня»** — только статус связи (в мастере «Сегодня» есть) | P2 |
| 5 | **Авто-определение дней ног из привязанного PL/BB-плана** — сейчас только ручной legDays | P2 |
| 6 | Варианты плана пересобираются при каждом изменении шага 1 (3×buildCardioCycle на кей-чейндж) — при 104 неделях избыточно | P3 |
| 7 | Нет «руководства пользователя» (как пользоваться инструментом) | P3 |
| 8 | Нет интеграции кардио-сессий в календарь тренировочного дневника (есть только .ics-файл) | P3 |
| 9 | Нет суммарной нагрузки дня (сила + кардио) | P3 |
