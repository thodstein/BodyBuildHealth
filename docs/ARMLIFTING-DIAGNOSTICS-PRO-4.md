## 2. Интернет-синтез (2025–2026, только проверяемое)

- **IronMind RT (ironmind.com/certification/rolling-thunder):** ручка 2 3/8" (60 мм) вращающаяся, 1993; WR М **130.5 кг Тюкалов 30.06.2013**; thumbless запрещён; ручка ~параллельно земле; локаут 1 с + down-сигнал; 1 минута, попыток внутри минуты без лимита; только обычный мел (магнезия), жидкий запрещён; протирка ручки перед попыткой; диски калиброванные/взвешенные. → Хаб: WR 130.5 верен; остальное в замер не встроено (L10).
- **IronMind Apollon's Axle (ironmind.com/.../apollons-axle):** гриф с дисками 450 мм (IWF/IPF); только **DOH, костяшки вперёд**; thumbless и hook запрещены; сумо разрешено; IPF-правила (полка на бёдра/движение вниз = нет); 1 с локаут; только мел. Числового WR в открытом доступе на странице правил нет (таблица — отдельно); **133 кг из нашего `PLATFORM_WR` — не рекорд IronMind**, честно маркировать внутренним до сверки с лидербордом. → L1.
- **IronMind Hub (ironmind.com/.../ironmind-hub):** с 1990, традиция Норберга; WR М **44.80 кг Толонен 10.02.2019** (наш 45 — округление, допустимо с подписью); вес = Hub+пин+карабин (2.26 кг) + диски; старт — **все 5 подушечек на базе**, «дверная ручка» запрещена; ~параллельно земле; 1 с локаут; 1 минута. → L3/L10.
- **CoC + Silver Bullet (ironmind.com/.../coc-silver-bullet + CoC FAQ + буклет):** грипперы 11 ступеней: Guide ~60, Sport ~80, Trainer ~100, Point Five ~120, №1 ~140, №1.5 ~167.5, №2 ~195, №2.5 ~237.5, №3 ~280, №3.5 ~322.5, №4 ~365 фунтов (фунты — заводской рейтинг, не калибровка кг); сертификация М №3/3.5/4, Ж №2/2.5. Silver Bullet: **удержание диска 2.5 кг в закрытом №2 (Ж) / №3–№4 (М) на время**, гриппер новый из пакета, пуговица не глубже кромки, все 4 пальца на ручке, вертикально, касание мизинцем пули = стоп. Тренировочный канон: **warm (10–12 легко) → work (5–7 до отказа, 1–3 сета) → challenge (частички/негативы/холды), 2–3×/нед; 10–12 повторов = пора на следующий; 20–25 повторов = закрытие следующего**; приоритеты: crush первым, pinch/support после или в другой день; strap holds (Брукфилд), негативы (Кинни), IMTUG, EGG/расширители. → L5/L15.
- **Armlifting USA 2026 (armliftingusa.com):** формат — **last-man-standing, 60 сек на попытку, промах = выбыл, вниз по весу нельзя** (Super Series Rules); зачёт в % (600 очков за 2 стейджа). События 2026: **Raptor 1.75" одноручный, Fat Gripz 2" DOH двуручный, Hub freestyle, Country Crush 2" двуручный, Saxon 3×4, Grandfather Clock (Rogue), Anvil (SSE/Rogue), Axle 60 мм (2 3/8") на макс, Saxon 2×5 medley** (Worlds: Axle + Anvil + Saxon-medley; Arnold: Rogue Axle + Saxon 3×4 + GFC; Super Series Stage 1/2). Весовые: **М 60/70/80/90/100/110/125/125+, Ж 55/60/65/70/80/90/100/100+, Masters 50+ (90/110/110+ М; 80/80+ Ж) + Masters 60+, Teen** (Super Series/Season Rankings). Рекорды — **20+ живых лидербордов Google Sheets** (Rolling Thunder, Apollon's Axle, Rogue Axle, Saxon 3×4 и 60 мм, Saxon 2×5, GFC, Anvil, Country Crush 2", Monster 3", Raptor 1.75/2/3", Hub traditional, Silver Bullet, IronMind Block, Little Big Horn). Фиксированных разрядных таблиц нет — только лидерборды. → L6/L7/L8.
- **Pinch-наука (Mathiowetz 1985 — золотой стандарт; Werle 2009 n=1023; Grippit n=566):** 3 вида щипка (tip/key/palmar), нормы по полу/возрасту/руке; доминанта +5–10% (щипок — меньше, чем хват); щипок стабилен 20–59 лет, спад после 60; рост/вес/регулярный тренинг — предикторы; корреляция хват↔щипок r≈0.64 (Ж). Практический ориентир тренинга: **+15–30% за 8–12 нед, plate pinch 3×20–30 с, 2–3×/нед, шаг +2.5–5% в 1–2 нед**. Клиника: >15% межручная разница — на осмотр. → Подписи к асимметрии и ожиданиям прогресса (не гейты).
- **Типы хвата (IronMind/Armlifting USA консенсус):** support (толстый гриф/RT/фермер) → pinch (только пальцы, большой решает) → crush (эспандеры). Частая ошибка — качать crush при отстающем support/pinch. → L15 (рецепт по weakest).

- Ввод: `pinchKg` (макс. щипок, кг) + `pinchSec` (удержание, с) — два независимых поля; отчёт — две строки (обе internal: единого WR щипка нет — ширина/1H-2H/федерация, Gods of Grip 2024–2025; кг считается от внутреннего ориентира 80/45, удержание — от 15 с).

### A3. CoC: закрытие + Silver Bullet раздельно (закрывает L5)

- DoD: движок + хаб + 2 теста.

### A7. L/R для одноручных (закрывает L9)

- Тесты: все «да» → зачётный; один «нет» → тренировочный.

### A9. Честный тотал + раздельный avg (закрывает L12+L13)

- Тесты: тренд считается; рецепт содержит ключевую строку.
- DoD: хаб-блок + 3 теста.

## 4. Осознанно НЕ делаем (с причинами)

1. **Разрядные таблицы SAR/Armlifting USA в кг** — их нет, только живые лидерборды; Excalibur и несверенные снаряды остаются «фактом без %».
2. **Женские WR всех снарядов** — кроме RT известна только часть; несверенное — с честной пометкой.
3. **Нормативы времени Silver Bullet** — IronMind даёт процедуру, не норматив; только личный рекорд.
4. **1ПМ/предикт по скорости для хвата** — LVP-профилей для RT/pinch нет; VBT остаётся в арм-хабе, сюда не тянем.
5. **Методика весогонки** — только арифметика до границы класса.
6. **Он-девайс видео/авто-углы** — вне скоупа диагностики хвата.
