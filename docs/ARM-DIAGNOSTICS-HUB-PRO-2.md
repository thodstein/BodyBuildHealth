# Арм-диагностика ХАБ — PRO-2: без бокового скролла, без пустот + план PRO

Статус: **ШИПИНГ (скролл/пустоты) + ПЛАН (эпики P1–P7)**. База: `ARM-DIAGNOSTICS-PRO-PLAN.md` (выполнен 100% + D + R1).

## 0. Что сделано в этом раунде (только подача, логика/строки/aria 1-в-1)

**Жалобы:** «прокрутка в сторону» + «пустые места».

**Корень скролла:** хаб (`.train-armdiag`) осознанно исключили из правила №6
(«ленты → перенос» действовало только на `.train-arm`) — в хабе остались
`overflow-x:auto + flex-shrink:0 + nowrap` на 4 лентах: `.ad-chips`, `.ad-strip`,
`.ad-steps` (5 табов), `[data-arm='hist-strip']` (12 нед истории). На узком
телефоне/десктопе они давали боковой скролл страницы.

**Фикс (`arm-design.css`, хвост):**
- `.train-armdiag`: `.ad-chips/.ad-strip/.ad-steps/hist-strip` → `flex-wrap:wrap +
  overflow-x:visible + snap:none`, дети `flex-shrink:1` (прецедент №6, sticky
  `.ad-steps` сохраняется — wrap липкость не ломает).
- Страховка: `.ad-wrap/.ad-tabpanel → overflow-x:clip`, `.ad-mono → width:100%`.
- Все селекторы с `:is(.train-armdiag)` — префикс-чекер цел.

**Пустоты (`arm-design.css` + 2 инлайн-константы `arm-hub-panels.tsx`):**
- `.ad-wrap 12→8`, `.ad-card 16/12→12/8`, `.ad-sec 13/12→10/8`, `.ad-sec-t 10→6`,
  `.ad-head 12→8`, `.ad-banner 12→8`, чипы/полосы/история `10→4` низа,
  `video-ph 22→12`, `empty 26→16`, `cta 10/12→8/8`, `list 10→8`, `finding 6→4`,
  `volbar 8→6`; `HUB_HERO 14/16→10/12`, `HUB_SECTION_GAP 8/8→6/6`.
- Логика/строки/aria/хуки (`hub-head/hub-tabs/hub-strip/hist-strip/wp-groups`)
  не тронуты.

**Проверено:** `arm-diagnostics-hub 30/30` + `hub-tabpanel 4/4` + `arm-top-ui 16/16`
+ `apk-arm-pack 17/17` → **67/67**, `tsc --noEmit` 0 (6GB), `verify:apk-design` OK.

| Узел | Состав | Проблема |
|---|---|---|

## 2. Интернет-синтез (что есть в мире, чего нет в хабе)

- **Техники (Wikipedia/arm-wrestling):** hook = супинация + бицепс/кисть;
  toproll = пронация + rising + back pressure + posting; press = плечо/грудь/
  трицепс, только из нейтрали, новичкам опасен (тендоны локтя). → В хабе
  техника — чип, без привязки норм/углов/рисков к технике.
- **Травмы (PMC10315927; JCT review):** спиральный перелом дистальной трети
  плеча (Holstein–Lewis 12.A1/A2, риск лучевого нерва) — самая частая травма;
  софт-тишью → возврат ~1 мес, перелом → месяцы + ниже DASH. Механика —
  высокий ротационный момент. → В хабе есть humerus-guard + side-прогрессия
  ≤10%/нед, но **нет скрининга red-flags** (боль/щелчки/онемение → стоп).
- **WAF Rules 2025 (waf-armwrestling.com):** фолы (отрыв локтя, сгиб кисти,
  касание плечом, фальстарт), ремень/strap-старт, сгонка веса, L/R — отдельные
  зачёты, возрастные группы. → В хабе Table-IQ считает фолы/срывы/ремень, но
  **нет правил-памятки** (что фол → что чинить) и привязки весогонки к классу.
- **Оптимум угла предплечья (ScienceDirect 2095034921000945):** EMG-зависимость
  от угла — обоснование для angle-бейджей (уже есть) + **норм по технике нет**.
- **Grip-миp (IronMind/GripBoard):** RT WR M 130.5 / F 77.2, Saxon Axle 133,
  CoC-уровни, pinch-нормы. → В хабе захардкожены, но **нет таблицы «ты vs норма
  твоего класса»**.
- **Bezkorovainyi ARM1 (патент #43082, WO2026106582A1):** Fmax/F100/F500/t05F/
  fatigue-тренд. → В хабе считается, но **нет популяционных норм** (что такое
  «хороший F/t»).
- **ACWR/тендоны:** per-muscle ACWR уже есть; **нет связки** «ACWR-danger точка →
  причина volume/fatigue в топе» (данные рядом, вывод не соединён).

## 3. План PRO (эпики P1–P7, каждый — свой коммит pathspec)

- **P1 Навигация-мастер (навигация, не логика):** нумерованные шаги
  `1 Тело → 2 Точки → 3 Тесты → 4 План` поверх существующих 5 табов
  (маппинг: тело=grip-верх, тесты=grip-низ+strength, план=P0);
  HowTo-портянка → 4 строки по шагам. DoD: новичок доходит до «Применить» без чтения доки.
- **P2 Дедуп панелей (главный пожиратель пустот):** `HubOutput` → схлопнуть в
  P0 (findings остаются в Head одной строкой); `HubTableStrip` удалить
  (полоса живёт в `Pressure`); CTA оставить ОДИН внизу (`HubAction`),
  верхний — убрать; Force Vector — только в `Grip`; scoring-кольцо — только в
  Head. DoD: −2 AdCard со экрана, 0 дублей bio/strip/scoring.
- **P3 Нормы-бенчмарки («ты vs мир»):** таблица RT/Axle/pinch/side/back vs
  IronMind WR + WAF-класс (bw×0.6/×0.8 уже считаются — показать дельту %);
  F/t-нормы Bezkorovainyi qualitative (низко/норма/элита) вместо голых цифр;
  ROM-нормы (сгиб ≥80°/разгиб ≥70°/прон-суп ≥80°) рядом с чипами мобильности.
  DoD: каждая цифра хаба имеет «норма/дельта».
- **P4 Видео/VBT PRO:** Kinovea-метрики + SRD-бейдж уже есть → добавить
  Vorobyev-тип траектории (внутрь/наружу/прямо уже классифицируется —
  показать словами + что чинить); VBT-пороги точки показать шкалой
  warn/stop, а не строкой. DoD: видео-ответ = «тип + реальное/шум + коррекция».
- **P5 Безопасность red-flags:** скрининг перед тестами (острая боль/отёк/
  щелчки/онемение/недавний перелом → 🔴 стоп + return-to-pull, а не точки);
  press-гейт новичкам (как в Wikipedia-предупреждении); side-гейт уже есть —
  поднять в шапку при срабатывании. DoD: опасное состояние нельзя пропустить.
- **P6 Экспорт/сценарии:** HTML/CSV/печать уже есть → + «сценарий замера»
  (снапшот всех полей, кап 6, как годовые сценарии) + сравнение «было/стало»
  по RT/F-t/точкам. DoD: прогресс 12 нед виден в 1 клик.
- **P7 Мост 2.0:** payload уже обогащён (причины/топ/spec/мобильность/ACWR/
  bilateral/попытки/матчап/Table-IQ) → добавить превью «что уедет в
  конструктор» (список групп + дни + гейты) + честный пустой стейт.
  DoD: surprises от моста = 0.

**Вне скоупа (осознанно):** железо/Hands-модель в бандл, годовой план из хаба,
ICS-экспорт, постановка диагнозов (только скрининг + «к врачу»).
