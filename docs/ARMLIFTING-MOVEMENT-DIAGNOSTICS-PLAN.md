## 2. Интернет-синтез (только проверяемое, 2024–2026)

- **IronMind (RT/Hub/Block/Silver rules, referee forms):** RT — вращающаяся ручка
  60.3 мм × 19 см (V1 чёрная 1993–2008 → V2 тёмно-синяя → V3 с закрытыми торцами;
  вращение на рекордных весах — известная проблема версий, Wikipedia);
  центр хвата, thumbless запрещён, ~параллельно земле, локаут 1 с + down-сигнал,
  протирка + только обычная магнезия, касание рамки/тела = no lift.
  Hub — все 5 подушечек на базе, «дверная ручка» запрещена, ~параллельно, без
  протяжки по ноге, старт с касания плиты. Block — центр, thumbless запрещён,
  ~параллельно, без касания тела. Silver — диск 2.5 кг в закрытом №2 (Ж) / №3–4 (М),
  новый гриппер из пакета, вертикально, касание мизинцем = стоп. Контест: 60 сек
  на попытку, попыток без лимита внутри минуты. CoC FAQ: канон warm 10–12 →
  work 5–7 до отказа 1–3 сета → challenge (частички/негативы/холды), 2–3×/нед.
- **CTD-куб (Crushed-to-Dust):** сила хвата = prime mover (thumb vs 4 fingers) ×
  позиция (open vs closed) × интенсивность (1RM vs endurance) = 8 типов.
- **SBS Gill 2024:** support/pinch/crush — разные навыки, слабо коррелируют;
  FDP/FDS — главная сила сгибателей, FPL — большой; ECRL/ECRB/ECU держат позицию —
  при слабости включается EDC (разгибает и пальцы) и открывает хват; запястье
  в нейтрали vs сгибе меняет длину FDP/FDS и результат.
- **NSCA (Effective methods of grip):** flexors — сила, extensors — стабилизация;
  towel-модификации, plate pinch гладкими наружу, flips, carries 20–50 м, bottom-up,
  односторонние; хват в конец сессии; 2 сета достаточно.
- **PoinT GO / GoldenGrip / Gripnatic 2025–2026:** 4 типа (crush/support/pinch/extension);
  дисбаланс flex>ext → эпикондилиты; экстензия с резинкой 15–25, роллер, wrist curls 12–15;
  support — холды 30–60 с, pinch — 20–30 с, crush — 5–8; сухожилия 8–12 нед.
- **Клиника (ASHT 2024, Pabau 2026, IJSPP finger-strength):** щипковые паттерны
  lateral/tip/palmar — не взаимозаменяемы (lateral — быт, tip — FPL-сигнал);
  стандартизация позиции обязательна (угол локтя/высота меняют цифры);
  pinch tip — самый отзывчивый к изменениям; AIN-тест (O-shape → pulp-to-pulp =
  слабость FPL + FDP index); сила щипка нормируется к массе тела (0.28–0.6).
- **Armlifting USA (home/beginners):** спорт = «пауэрлифтинг хвата»;
  стартовые снаряды RT / Axle DOH / Saxon 3"; last-man-standing, промах = выбыл.
- **Gods of Grip (rolling handle tips):** отдельная техника вращающейся ручки
  (аксессуары + разбор техники) — существует как жанр, у нас не покрыт.

## 3. Разрывы: что хаб НЕ диагностирует (7 штук, все реальные)

| # | Разрыв | Почему это движение, а не статика |
|---|---|---|
| G1 | Нет фазовой развёртки попытки во времени | Сейчас точка срыва — один чип. Реально RT-ролл: посадка → отрыв → вращение ручки → дрейф/перекос → стойка 1 с → down. Pinch/Hub: отрыв → микро-скольжение → раскрытие → падение. Без тайминга «где» не отличить «вращение убило» от «пальцы открылись». |
| G2 | Нет антропометрии кисти | Толстый гриф 60 мм vs Hub vs щипок — разная цена размера ладони (Thomas Inch-проблема). У нас одинаковые %WR для ладони 19 см и 22 см. SBS: длина FDP/FDS решает. |
| G3 | Нет холд-кривой (время-сила) | Тест-батарея — одна цифра (pinch 20 с). Нет пары «макс vs 70% холд» → не отличить пиковую силу от выносливости удержания, хотя точки hold_short/hold_long именно про это. |
| G4 | Нет контроля инвентаря/условий | V1/V2/V3 RT крутятся по-разному на рекордах; некалиброванные диски, жидкий мел, холодный зал, диаметр (60 vs 50 мм) — всё это «срыв», а не слабость. У нас только 2 фола из 5 условий. |
| G5 | Нет видео-разбора (поза/углы) | Арм-хаб имеет Kinovea-CSV + SRD + тип траектории; ТА-хаб — углы + bar-path. У армлифтинга — ноль: запястье (нейтраль/сгиб), параллель снаряда, дрейф по ноге — всё «на глаз». |
| G6 | Нет тактики попытки (60-сек окно) | D7 вырезал попытки/LMS из хаба как «соревы». Но 60 сек / промах = выбыл / выбор opener — это и есть движение помоста. Без симулятора попыток диагностика не доводится до заявки. |
| G7 | Боль — бинарная, без карты | pain=true стопает всё. Клиника различает: FPL/FDP (AIN), ECRL/ECU (латеральный локоть), перепонка/кожа (щипок), запястье. У нас нет «где болит → что разгрузить, что можно». |

Осознанно НЕ делаем: VBT-датчики/динамометры с Bluetooth (нет канона интеграции),
нормативы в кг для Raptor/Crush/Clock/Anvil (только лидерборды — честный факт),
поперечные «эталоны» ширины щипка в см (федерации различаются — Gods of Grip 2024–2025).

## 5. Порядок и оценка

M1→M2 (ядро движения) → M5 (дешёвые условия, режут ложные «слабости») →
M3+M4 (рука + кривая) → M8 (карта боли, безопасность) → M6 (видео) →
M7 (тактика) → M9 (мост/экспорт). Ориентир: 9 волн ≈ D1–D21 по объёму,
каждая — своим коммитом pathspec, без пуша (очередь чужих).
