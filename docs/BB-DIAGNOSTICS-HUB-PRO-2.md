## 2. Аудит хаба (что есть сейчас)

- **Слабые**: гранулярные 1–2 + авто-кандидаты (дневник/объём/замеры) + причины (объём/восстановление/
  техника/сила/подвижность/усталость) + e1RM-тренд 28д + топ-3 + покрытие головок + вставка в план
  + журнал снимков + откат. Сильное место хаба.
- **Симметрия**: замеры 14 + запястье (Маккаллум) + пол + триада шея=бицепс=голень + женские заметки
  + трекинг снимков с дельтами. Слабые места: идеал Ривса/Маккаллума — ориентир 1950-х без поправки
  на рост/тип телосложения; L/R дельты есть, а унилатеральной добивки слабой стороны в плане нет.
- **Упражнения**: аудит портфеля (СФР/длина/углы/строгие/подрегионы/усталость) + разбор 12 признаков +
  техника + топ-3 замен + библиотека. Сильное место. Слабые места: разбор держится на ручном вводе
  «как выполняешь»; видеоразбора штанги в ББ-хабе нет (только текстовое поле траектории).
- **Стимул**: длина/середина/пик + база/изоляция + жгуты + баланс плана. Дубль с аудитом портфеля
  (та же длина/углы двумя словами) — кандидат на слияние.
- **Объём**: чип-факт 7д + канон-минимум/норма/максимум. Честно read-only от дневника; без дневника — пусто.
- **Восстановление**: нагрузка по мышцам + сон + скорость + общий снимок. Нет HRV/пульса/готовности,
  нет травмы-красного флага, нет «сегодня можно/нельзя».
- **Подвижность**: присед-тест 6 + колено-к-стене + голеностоп + подпятка-ретест + скорость +
  таблица траектории + в профиль. Черновик позы — мок (не live).
- **Мост**: `weakpoints` (зоны + канон + оценка + симметрия + стимул + ACWR + присед + скорость +
  причины + топ-id + головки + спец-блок + сон) → ББ-авто; вставка коррекций в сохранённый план
  пословно с историей; печать HTML + таблица CSV.

## 3. Интернет-синтез (2026-09)

- **Объём-ориентиры** (Schoenfeld 2017 доза-ответ 10+ сетов > 5–9 > <5; Israetel MEV/MAV/MRV):
  MEV 4–8, MAV 10–20, MRV 20–26 по группам; малые (бицепс/трицепс) раньше упираются в потолок
  из-за косвенной нагрузки от базы; старт блока у MEV → +1–2/нед → разгрузка у MEV.
  У хаба ориентиры уже канонные (`volume-landmarks`), дыр нет.
- **Растянутая позиция** (Maeo 2021–2023: трицепс над головой +50% длинной головки, хамсы/ягодицы
  ×2 на длине; Wolf 2025: растянутые частичные ≈ полная амплитуда > укороченных; StrongerByScience:
  «не магия растяжки, а длина + угол»): вывод — держать скоринг длины/углов (уже есть),
  укороченные добивки — только после закрытия длины. У хаба это уже ядро (СФР/длина/углы).
- **Частота и специализация**: 2–3×/нед на отстающую, остальные на поддерживающем минимуме;
  специализация 1–2 мышцы (уже: кап 2 + спец-блок 4–8 нед). Дыр нет.
- **Чего нет у конкурентов-хабов, но нужно**: per-сторона объём (L/R дисбаланс в сетах, не только в см);
  готовность дня (сон+H RV+боль → «сегодня объём/сбавь»); красный флаг травмы; видео-штанга
  с SRD-порогом как в ТА-хабе; live-поза вместо мока; женские нормы симметрии (талия/бёдра)
  глубже одной строки.

## 4. PRO-план (эпики P1–P7, каждый — движок + хаб + тест)

- **P1 L/R-объём**: per-сторона сеты из дневника (унилатеральные + половина билатеральных по маркеру
  руки, если есть) → `asymSetsPct` по группам рук/ног → вердикт (≥12% — добивка слабой +15–25%
  в пределах MRV, как в арм-хабе bilateral). Хаб: строка «Слабее: левая → добивка» в Слабых.
- **P2 Готовность дня**: сон + боль/д entered + скорость-потеря + нагрузка → светофор
  (зелёный/жёлтый/красный + «сегодня: объём/техника/сон») в Восстановлении. Без диагнозов.
- **P3 Красные флаги**: острая боль/отёк/онемение/щелчки + травма-гейт вставки (при флаге — только
  техника/разгрузка, вставка объёма блокируется с честным текстом). Только скрининг.
- **P4 Видео-штанга**: поле траектории уже есть → разбор `xLoop/yMax/vMax` + SRD-бейдж 4/6 см
  (reuse `strength-sport-video`) + тип траектории в Упражнениях. Без нового ввода.
- **P5 Live-поза**: `PoseProvider` из ТА-хаба вместо мока (таз/колено/голеностоп/плечо live +
  «проверь себя» чипами). Мок удалить.
- **P6 Стимул-слияние**: Стимул-таб оставить чипом-диагнозом (длина/жгуты/баланс), детали углов —
  только в Упражнениях (убрать дубль текста). Тесты на дубли.
- **P7 Женская симметрия**: талия/бёдра/бедро в `femaleSymmetryNotes` расширить (WHR-коридор +
  фаза цикла как в питании) + детские (14–15) гарды как в арм-хабе teen-гейт.
