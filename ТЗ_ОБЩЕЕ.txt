## 15. ПРОГНОЗНЫЙ АНАЛИТИК (PREDICTIVE ANALYTICS) — ПОЛНАЯ ДЕТАЛИЗАЦИЯ

### 15.1 Краткосрочные прогнозы (на 7 дней)

**Модель:** ARIMA(1,1,1) или экспоненциальное сглаживание Холта-Уинтерса (для сезонных данных).  
**Параметры для прогноза:**
- Readiness score (0–100)
- Fatigue score (0–100)
- MRR (0–1)
- HGI (0–1)
- Субъективные: настроение, либидо, качество сна (из чекапа)

**Алгоритм:**
1. Накапливаем ежедневные значения за последние 30 дней.
2. Применяем модель ARIMA(1,1,1) с автоматическим подбором коэффициентов (методом максимального правдоподобия).
3. Выдаём прогноз на 1, 3, 7 дней вперёд ± 95% доверительный интервал.
4. Если прогнозируемое значение падает ниже критического порога (например, readiness <40) — система выдаёт предупреждение: «Через 3 дня ожидается критическое снижение восстановления. Рекомендуем запланировать день отдыха».

**Пример вывода:**
```
📈 ПРОГНОЗ READINESS НА БЛИЖАЙШИЕ 7 ДНЕЙ
Сегодня: 58 (средний)
Через 3 дня: 52 ± 5 (вероятность снижения до <40: 12%)
Через 7 дней: 48 ± 7 (вероятность снижения до <40: 38%)
⚠️ Рекомендация: запланировать делод на день 5–6.
```

### 15.2 Долгосрочные прогнозы лабораторных маркеров (на 4, 8, 12 недель)

**Модель:** экспоненциальное сглаживание с параметром α = 0.3 + байесовское обновление.  
**Для каждого маркера** (гематокрит, ALT, ЛПВП, ЛПНП, креатинин, eGFR, TT, E2, пролактин) система строит прогноз на основе:
- последних 3–5 фактических значений
- базовой скорости изменения (например, гематокрит растёт на 2–3% в неделю на тестостероне)
- фармакокинетических поправок (период полувыведения препарата)

**Формула прогноза для гематокрита:**
```
Hct_pred(t) = Hct_baseline + (0.02 × Σ (доза_тестостерона/300) × t) × (1 - 0.1×t/4)  (насыщение после 8 недель)
```
Где t – недели.  
Прогноз обновляется каждые 2 недели при поступлении новых анализов.

**Пример вывода:**
```
🔬 ПРОГНОЗ ГЕМАТОКРИТА (текущий: 50%)
Через 4 недели: 53.5% ± 1.5% (вероятность превышения 54%: 65%)
Через 8 недель: 55% ± 2% (вероятность превышения 54%: 92%)
🔴 Рекомендация: запланировать донацию крови на 3–4 неделе или снизить дозу тестостерона.
```

### 15.3 What-if сценарии (интерактивный режим)

Пользователь может изменять один или несколько параметров и видеть, как изменятся прогнозы рисков и лабораторных маркеров.

**Доступные для изменения переменные:**
- Доза каждого препарата (+50%, +100%, -50%, отмена)
- Калорийность (+500 ккал, -500 ккал)
- Кардио нагрузка (+2 часа/нед, -2 часа/нед)
- Сон (+2 часа, -2 часа)

**Алгоритм:** система пересчитывает `drugLoad`, `nutritionFactor`, `trainingFactor` и заново вычисляет риски (раздел 13) и прогнозы лабораторных. Результат сравнивается с базовым сценарием.

**Пример вывода:**
```
🔄 WHAT-IF: СНИЖЕНИЕ ДОЗЫ ТРЕНБОЛОНА С 200 МГ/НЕД ДО 100 МГ/НЕД
- Риск нейротоксичности: снижается с 44% до 28% (-16 п.п.)
- Риск дислипидемии: снижается с 48% до 35% (-13 п.п.)
- Прогноз гематокрита через 4 недели: 51.5% вместо 53.5%
- Ожидаемый прирост мышечной массы: снижение на 15–20% (компромисс)
✅ Рекомендуется для пользователей с COMT Met/Met.
```

## 16. СМАРТ-АССИСТЕНТ — ПОЛНАЯ ДЕТАЛИЗАЦИЯ

### 16.1 Глоссарий (всплывающие подсказки)

При наведении/клике на любой термин в интерфейсе (в том числе внутри статей, рекомендаций, результатов расчётов) открывается всплывающая карточка с определением, единицами измерения (если применимо) и ссылкой на соответствующую статью или внешний источник.

**Пример словаря (фрагмент):**
- **RIR (Repetitions in Reserve)** – количество повторений «в запасе» до отказа. RIR 2 означает, что вы могли бы сделать ещё 2 повторения. Используется для регулировки интенсивности.
- **гематокрит (Hct)** – доля эритроцитов в крови. Норма для мужчин 40–52%, для женщин 36–46%. Повышение >54% критично.
- **EC50** – концентрация препарата, при которой достигается 50% максимального эффекта. Используется в фармакодинамике.

### 16.2 Чат-бот (встроенный) с базой знаний

Пользователь может задать вопрос в текстовом поле «Спросить ассистента». Система ищет ответ в базе из 200+ типовых вопросов и ответов (Q&A), составленной на основе статей и клинических рекомендаций.

**Примеры вопросов:**
- «Как снизить пролактин на тренболоне?»
- «Что делать, если гематокрит 55%?»
- «Нужно ли чистить печень после курса оралов?»
- «Какая доза телмисартана для профилактики?»

**Алгоритм:** поиск по ключевым словам + ранжирование по релевантности (TF-IDF). При отсутствии точного ответа – предложение обратиться к врачу или перейти в соответствующий раздел статей.

### 16.3 Голосовой ввод (Web Speech API)

- **Активация:** кнопка «🎙️» в дневнике питания, в разделе симптомов, в чекапе.
- **Функции:**
  - Запись голоса → транскрипция → парсинг ключевых фраз.
  - Пример: «Я съел 200 грамм куриной грудки и 150 грамм гречки» → автоматическое добавление в дневник.
  - Пример: «У меня болит голова и усталость 7 из 10» → запись симптома с оценкой.
- **Офлайн-распознавание** (при отсутствии интернета) – используется встроенный в браузер движок (доступен в Chrome, Safari).

### 16.4 Еженедельный чекап (воскресенье, через Telegram-бота)

Каждое воскресенье в 19:00 (настраивается) Telegram-бот отправляет сообщение:
> «📋 ЧЕКАП НЕДЕЛИ (займёт 1 минуту)  
> 1. Как вы спали в среднем за неделю? (1–10)  
> 2. Уровень стресса за неделю? (1–10)  
> 3. Боль в мышцах (DOMS) за последние 3 дня? (1–10)  
> 4. Либидо (0–10)?  
> 5. Общее самочувствие (1–10)?»

Пользователь отвечает числами (или кнопками). Ответы сохраняются, обновляется `Recovery score` (за счёт поправки на сон и стресс), `Fatigue score`, а также корректируется MRR и HGI.

### 17.3 Trust Score (0–100) — расчёт

Trust Score – показатель **достоверности данных** и **приверженности рекомендациям**. Влияет на вес персонализации (чем выше Trust, тем более агрессивные (но безопасные) рекомендации могут быть выданы, так как система «доверяет» вводимым данным).

**Формула:**
```
Trust = min(100, 
  (заполнение_дневника × 20) + 
  (выполнение_рекомендаций_питания × 30) + 
  (соответствие_лабораторных_заявленному_приёму × 30) + 
  (положительные_отзывы_тренера × 20)
)
```
- **заполнение_дневника:** доля дней с заполненным дневником питания за последние 30 дней (от 0 до 1).
- **выполнение_рекомендаций_питания:** средний процент выполнения целевых калорий и белка (отклонение не более 15% → 1, иначе 0.5).
- **соответствие_лабораторных_заявленному_приёму:** система сравнивает фактический уровень тестостерона (лаборатория) с ожидаемым на основе заявленной дозы. Отклонение <30% → 1, 30–50% → 0.5, >50% → 0.
- **положительные_отзывы_тренера:** тренер может поставить оценку приверженности (0–5 звёзд). Преобразуется в 0–1.

**Влияние на персонализацию:**
- Trust ≥80 – система может рекомендовать более высокие объёмы тренировок (ближе к MRV), более жёсткие диеты (дефицит до 25%).
- Trust 40–79 – стандартные рекомендации (на уровне MAV, дефицит 15–20%).
- Trust <40 – консервативный режим (объём на уровне MEV, дефицит не более 10%), усиленный контроль.

## 18. ФЕРТИЛЬНОСТЬ И ПКТ – СПЕРМОГРАММА (ПОЛНЫЙ ПРОФИЛЬ)

### 18.1 Параметры спермограммы (вводимые пользователем или через OCR)

Система поддерживает ввод следующих параметров (по стандарту WHO 2021):

| Параметр | Единица | Норма (референс) | Влияние на индекс фертильности (вес) |
|----------|---------|------------------|--------------------------------------|
| Объём эякулята | мл | ≥1.5 | 0.15 |
| Концентрация сперматозоидов | млн/мл | ≥16 | 0.20 |
| Общее количество сперматозоидов | млн | ≥39 | 0.10 |
| Подвижность прогрессивная (PR) | % | ≥30 | 0.25 |
| Подвижность непрогрессивная (NP) | % | ≥1 (не нормируется) | – |
| Морфология (нормальные формы по Крюгеру) | % | ≥4 | 0.20 |
| pH | – | 7.2–8.0 | 0.10 (бинарно) |
| Вязкость | – | нормальная (не повышена) | штраф -5% если повышена |
| MAR-тест (антиспермальные антитела) | % | <50 | штраф -10% если >50 |
| Лейкоциты | млн/мл | <1 | штраф -15% если >1 |
| Агглютинация | – | отсутствует | штраф -20% если есть |

### 18.2 Расчёт индекса фертильности (IF, 0–100)

```
IF = 100 × [ (V/1.5 × 0.15) + (C/16 × 0.20) + (T/39 × 0.10) + (PR/30 × 0.25) + (Morph/4 × 0.20) + (pH_norm × 0.10) ] × поправки
```
- V, C, T, PR, Morph – фактические значения (ограничены референсом сверху, то есть не более 1).
- pH_norm = 1, если pH 7.2–8.0, иначе 0.8.
- **поправки:** если вязкость повышена → ×0.95; если MAR>50 → ×0.9; если лейкоциты >1 → ×0.85; если агглютинация есть → ×0.8.

**Интерпретация:**
- IF ≥ 60 → нормальная фертильность.
- IF 30–59 → умеренное снижение, требуется коррекция (добавки, ПКТ, изменение образа жизни).
- IF < 30 → критическое снижение, обязательная консультация репродуктолога.

### 18.3 Прогноз восстановления фертильности после курса ААС

**Модель (экспоненциальное восстановление):**
```
IF(t) = IF_base + (IF_target - IF_base) × (1 - e^{-t / τ})
```
- `IF_base` – индекс фертильности сразу после курса (или текущий).
- `IF_target` – целевой индекс (70–100 в зависимости от возраста).
- `τ` – постоянная времени восстановления (в неделях). По умолчанию τ = 12 недель (сперматогенный цикл). При длительности курса >16 недель τ увеличивается до 16–20 недель. При использовании HCG на курсе τ сокращается до 8–10 недель.

**Вывод для пользователя:**
```
📊 ПРОГНОЗ ВОССТАНОВЛЕНИЯ ФЕРТИЛЬНОСТИ
Ваш текущий индекс фертильности: 34 (умеренное снижение)
Прогноз через 6 недель: IF = 52 (нормализация концентрации)
Прогноз через 12 недель: IF = 68 (нормализация морфологии и подвижности)
Рекомендуемая ПКТ: кломифен 25 мг/день + HCG 1000 МЕ через день (14 дней) + цинк 30 мг, селен 100 мкг, витамин E 400 МЕ.
```

### 18.4 Рекомендации по улучшению фертильности (в блоке поддержки)

- **HCG** на курсе: 500–1000 МЕ 2–3 раза/нед, начиная с 3-й недели курса (предотвращение атрофии тестикул).
- **ПКТ (восстановление оси):** кломифен 50 мг/день 2 недели, затем 25 мг/день 2 недели (или тамоксифен 20 мг/день 4 недели). HCG 2000 МЕ через день первые 2 недели ПКТ.
- **Нутритивная поддержка:** цинк (30 мг), селен (100 мкг), витамин E (400 МЕ), L-карнитин (1 г), коэнзим Q10 (200 мг).
- **Образ жизни:** исключение анаболических стероидов на период восстановления (минимум 3–6 месяцев), нормализация сна, снижение стресса.

### 18.5 Отображение в интерфейсе

- **Карточка «Фертильность»** в профиле: текущий IF, график динамики (если есть несколько спермограмм), прогноз восстановления.
- **Кнопка «Рекомендации по ПКТ»** – переход к персонализированному плану ПКТ с дозировками и длительностью.

## 19. КАЛЬКУЛЯТОРЫ И ФОРМУЛЫ (ОТДЕЛЬНЫЙ МОДУЛЬ) — ПОЛНЫЙ ПЕРЕЧЕНЬ

В отдельной вкладке «Калькуляторы» доступны следующие инструменты:

| Калькулятор | Формула/алгоритм | Примечание |
|-------------|------------------|-------------|
| **BMR (Mifflin-St Jeor)** | М: 10×вес(кг)+6.25×рост(см)-5×возраст(лет)+5; Ж: -161 | Учитывает пол |
| **BMR (Katch-McArdle)** | 370 + 21.6 × (вес× (100-%жира)/100) | Требуется % жира |
| **TDEE** | BMR × PAL (1.2–1.9) | PAL выбирается из таблицы |
| **HOMA-IR** | (глюкоза (ммоль/л) × инсулин (мкЕд/мл)) / 22.5 | >2.5 – инсулинорезистентность |
| **Скорректированный кальций** | Ca_общ + 0.8×(4.0 – альбумин) | Для диагностики гиперкальциемии |
| **Индекс атерогенности** | (ХС-ЛПВП) / ЛПВП | >3 – высокий риск |
| **Суммарный андрогенный индекс стека** | Σ (доза_i × AR_affinity_i / 100) | AR_affinity_i – относительно тестостерона (100) |
| **Дозировочный калькулятор** | (целевая_доза_мг_кг × вес) / концентрация_мг_мл = объём_мл; объём_мл × деления_шприца_на_1мл | Поддержка шприцов 0.3, 0.5, 1, 2, 5 мл, округление до 0.01 мл |
| **Калькулятор дефицита калорий** | TDEE – целевые_калории | Показывает скорость потери веса (кг/нед) |
| **Индекс массы тела (BMI)** | вес_кг / (рост_м)^2 | Классификация ВОЗ |

## 20. ИНТЕГРАЦИИ (ПОЛНЫЙ ПЕРЕЧЕНЬ)

### 20.1 Носимые устройства (Wearables) – Web Bluetooth API

**Поддерживаемые устройства:** Polar (H10, Vantage), Garmin (Forerunner, Fenix), Apple Watch (через связку с iPhone + WebKit).  
**Импортируемые данные:**
- ЧСС покоя (средняя за ночь, минимальная, максимальная)
- HRV (среднеквадратичное отклонение RR-интервалов)
- Количество шагов, расход калорий (активные)
- Фазы сна (глубокий, REM, лёгкий) – если доступно

**Порядок работы:** пользователь нажимает «Подключить устройство», браузер запрашивает разрешение на Bluetooth, выбирает устройство, система читает данные за последние 7 дней. Данные синхронизируются ежедневно (при открытии приложения).

### 20.2 API лабораторий (HL7 FHIR и REST)

**Поддерживаемые лаборатории (через отдельные коннекторы):**
- Инвитро (REST JSON)
- Хеликс (FHIR R4)
- CMD (FHIR R4)
- Медси (REST)
- Гемотест (экспорт PDF → OCR, до официального API)

**Алгоритм интеграции:**
1. Пользователь переходит в раздел «Анализы» → «Импорт из лаборатории».
2. Выбирает лабораторию, авторизуется (OAuth2, перенаправление на сайт лаборатории).
3. Система получает список доступных результатов за выбранный период.
4. Запускается маппинг и нормализация (раздел 12).
5. Результаты сохраняются с пометкой источника.

### 20.3 FatSecret API – детали

**Аутентификация:** OAuth 1.0a (3-legged).  
**Эндпоинты:**
- `GET /rest/food/v5` – поиск продуктов (`search_expression`, `page_number`, `max_results`, `region`, `language`)
- `GET /rest/food/v5?food_id={id}` – детальная информация (нутриенты, порции, изображения, аллергены)
- `GET /rest/food/v3?method=food.find_id_for_barcode` – поиск по штрихкоду

**Кэширование:** результаты поиска (по названию или штрихкоду) сохраняются в IndexedDB на 24 часа. Лимит запросов для базового аккаунта – 50 запросов/час.

### 20.4 Telegram Bot API

**Бот используется для:**
- Еженедельного чекапа (push-сообщения)
- Отправки уведомлений о новых статьях (если пользователь подписан)
- Отправки отчётов тренеру/врачу (PDF)
- Доставки сообщений тренера подопечному

**Команды бота:**
- `/start` – приветствие, ссылка на мини-приложение
- `/week_report` – отправить недельный отчёт в чат (в виде текста + ссылка на PDF)
- `/new_articles` – список новых статей за последние 7 дней

## 23. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ (TELEGRAM WEB APP) — ПОЛНЫЙ СПИСОК

### 23.1 Платформа и окружение
- **Веб-приложение** (SPA), встраиваемое в Telegram Mini App через `<script src="https://telegram.org/js/telegram-web-app.js">`.
- **Адаптивный дизайн** (mobile first): поддерживает разрешения от 360px до 1280px.
- **Язык реализации:** TypeScript (strict mode).
- **Сборка:** Webpack 5 или Vite.
- **Браузеры:** Chrome (iOS и Android WebView), Safari (iOS), Firefox (Android), Edge (Windows). Минимальная версия – 2 года от текущей.

### 23.2 Вычисления и производительность
- **Тяжёлые расчёты** (PK/PD интегрирование, прогнозирование ARIMA, Монте-Карло для рисков) выполняются в **Web Workers** (отдельный поток) без блокировки UI.
- **Кэширование промежуточных результатов** (расчёт рисков, прогнозов) в IndexedDB – повторное использование при неизменных входных данных.
- **Время отклика:**
  - Открытие приложения (холодный старт) – <3 секунд.
  - Пересчёт всех модулей (профиль + 12 недель фармакологии) – <2 секунд (на среднем смартфоне 2022+).
  - OCR одного скриншота – <5 секунд.

### 23.3 Безопасность и приватность
- **Все пользовательские данные хранятся локально** (localStorage, IndexedDB). Никакая информация не отправляется на сервер без явного согласия (кроме опциональной облачной синхронизации, которая будет реализована позже).
- **Шифрование чувствительных данных** (токены OAuth, номера телефонов, если есть) с использованием Web Crypto API (AES-GCM, 256 бит). Пароль шифрования запрашивается у пользователя при первом входе и хранится в sessionStorage (очищается при закрытии вкладки).
- **Дисклеймеры:** на каждой странице, где присутствуют рекомендации по фармакологии, обязательно отображается текст: «*Вся информация носит справочный характер. Не является медицинской рекомендацией. Применение любых препаратов возможно только после консультации с врачом.*»

### 23.4 Офлайн-режим
- **Service Worker** кэширует статические ресурсы (HTML, CSS, JS, шрифты) и статьи (последние 50 просмотренных).
- При отсутствии соединения:
  - Доступны все локальные данные (профиль, дневник, лабораторные, избранные статьи).
  - Невозможен поиск новых продуктов через FatSecret/USDA (но можно использовать локальную базу).
  - Невозможен импорт из API лабораторий.
  - Пользователь видит баннер «Офлайн‑режим. Некоторые функции ограничены».

### 23.5 Интеграция с Telegram SDK
- **Инициализация:** `Telegram.WebApp.ready()`
- **Тема оформления:** `Telegram.WebApp.themeParams` – цвета фона, текста, кнопок автоматически подстраиваются под тему Telegram (тёмная/светлая).
- **Кнопка «Назад»:** управляется через `Telegram.WebApp.BackButton`.
- **Основная кнопка (MainButton):** используется для ключевых действий (Сохранить профиль, Сгенерировать отчёт, Поделиться статьёй).
- **Закрытие приложения:** `Telegram.WebApp.close()`.

## 25. КРИТЕРИИ ПРИЕМКИ (ЧЕК-ЛИСТ – 120+ ПУНКТОВ, ОСНОВНЫЕ)

### 25.1 Профиль и Readiness
- [ ] Пользователь может ввести все обязательные параметры (раздел 3.1).
- [ ] Recovery, Nutrition, Support, Fatigue scores рассчитываются по формулам (3.2).
- [ ] Консервативный режим включается при критических значениях.

- [ ] Система выбирает сплит и программу на основе дерева решений (6.1).
- [ ] Вывод программы содержит название сплита, обоснование, понедельный график с упражнениями, RIR, комментарии.
- [ ] Объём тренировок (MV–MRV) корректируется по recovery, fatigue, weak points.
- [ ] При включении делода объём снижается на 30–50%, запрещаются отказные подходы.

### 25.3 Модуль питания
- [ ] Поиск продуктов работает в приоритете: LOCAL → FatSecret API → USDA → Open Food Facts.
- [ ] OCR распознаёт скриншоты MyFitnessPal, Yazio, FatSecret App.

### 25.4 Фармакологический модуль
- [ ] База содержит ≥130 препаратов с параметрами PK/PD.
- [ ] Расчёт концентраций использует 2-компартментную модель (RK4) в Web Worker.
- [ ] Толерантность и ребаунд моделируются.
- [ ] Байесовское обновление корректирует клиренс при вводе лабораторных данных.

### 25.5 Блок поддержки (БАДы + аптека)
- [ ] Понедельный план поддержки выводится с описанием механизма, дозировкой, синергией.

- [ ] Персонализация по генетическим SNP реализована.

### 25.6 Лабораторный модуль
- [ ] Нормализация единиц (UCUM) работает для всех маркеров (80+).

- [ ] Редактор может одобрить, отклонить, отправить на доработку.
