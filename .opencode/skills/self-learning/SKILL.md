# Self-learning: что запоминать и куда

Память проекта живёт в `docs/AGENTS-MEMORY.md`, навыки — в `.opencode/skills/<id>/SKILL.md`. Оба механизма обслуживает
плагин `.opencode/plugins/learning.ts`: инструменты `project_learn`, `project_learn_skill`, `project_learn_config` и
`context`-хук, который подмешивает свежие записи памяти в каждый запрос.

## Куда что писать

| Что выучено                                                    | Куда                                            |
| -------------------------------------------------------------- | ----------------------------------------------- |
| Факт/ловушка/договорённость, читается за 1–2 предложения       | `project_learn` → `docs/AGENTS-MEMORY.md`       |
| Процедура на 3+ шага, нужна регулярно                          | `project_learn_skill` → новый/обновлённый навык |
| Жёсткое правило, которое должно действовать всегда и для людей | `AGENTS.md` (руками, минимальный объём)         |
| История решений, аудиты, планы                                 | `docs/*.md`, не память                          |
| Состояние текущей задачи («осталось доделать X»)               | никуда: это живёт в сессии                      |

Память — не свалка. Запись должна отвечать на вопрос «что я сделаю иначе в следующий раз».

## Как писать факт

- `area`: `bb-engine`, `ui`, `data-import`, `backend`, `apk`, `research`, `tests`, `process`.
- `source`: обязателен, если факт про код или про медицину — `path:line`, команда с выводом или URL.
- Один факт = одна запись. Не склеивай пять наблюдений в абзац: их не найти и не удалить.
- Проверяй перед записью: `rg <ключевое слово> docs/AGENTS-MEMORY.md .opencode/skills AGENTS.md`. Дубликаты плагин
  отсекает по тексту, но смысловые повторы — твоя ответственность.

## Как писать навык

- Навык = «как делать», память = «что знать». Если текст начинается с «сначала…, потом…» — это навык.
- `description` — это триггер: по нему OpenCode решает, когда навык подгрузить. Пиши, когда применять, а не что внутри.
- Тело — императивные шаги, команды проверки и известные ловушки. Без истории и без «мы обсуждали».
- Обновление существующего навыка требует `overwrite: true`: сначала прочитай файл, потом переписывай целиком.

## Автообучение

`project_learn_config { auto: true }` включает автоматический шаг дистилляции после успешной сессии верхнего уровня
(одна короткая реплика в конце задачи, 0–3 факта). Субагентские сессии и сессии короче 8 сообщений пропускаются,
повторно для той же сессии шаг не запускается.

Включай, когда идёт длинная серия задач по одной области; выключай, когда нужен тишина и предсказуемая стоимость.
Ручной режим — команда `/learn`, он дешевле и даёт контроль над формулировками.

## Гигиена памяти

- Запись устарела — удали её или исправь, а не оставляй рядом противоречащую.
- Раз в крупный аудит просматривай `docs/AGENTS-MEMORY.md`: факты, которые уже закреплены тестом или навыком, из памяти
  убираются (тест — лучший носитель знания).
- Память читает каждая сессия: держи файл компактным (ориентир — до 200 строк), иначе он вытесняет контекст задачи.
