description: Разложить задачу по доменам, навыкам, источникам и проверкам
---

Вызови `project_route` / Code Mode `tools.project.route({ task: "$ARGUMENTS" })`.

Используй результат как первый шаг перед планом: загрузи перечисленные навыки, проверь источники и только затем
распределяй воркстримы. Команда ничего не меняет в коде.
