5. **Карточки из DashboardScreen** — перенести карточки "Системы организма" и "Ключевые риски"

**Логика взвешенной агрегации:**
```typescript
const weightedRisk = {
  pharma: rawRiskResult.overallRaw, // Риски от препаратов
  labs: labRiskResult.overallRaw, // Риски от анализов
  training: trainingResult.overallRaw, // Риски от перетренированности
  nutrition: nutritionResult.overallRaw, // Риски от дефицитов
  diagnostics: diagnosticsResult.overallRaw // Риски от исследований
};

const overallRaw = Math.max(...Object.values(weightedRisk));
const overallNet = calculateNetRisk(weightedRisk, supportCoverage);
```

**Визуализация:**
- Pie chart для распределения рисков по источникам
- Bar chart для сравнения сырого/нетто риска по источникам
- Timeline с трендами по источникам

**Детализация:**
- Для каждого системного риска показывать: `source: 'pharma'|'labs'|'training'|'nutrition'|'diagnostics'`
- Возможность фильтровать по источнику
- Кнопка "Показать источник" для каждого системного риска
