## Реализация

### Шаг 1: UI для показа исследований (ПРИОРИТЕТ)

**Файлы:**
- `src/ui/screens/PharmaScreen.tsx` - показывать исследования в карточке препарата
- `src/ui/screens/RiskScreen.tsx` - показывать исследования в детализации риска
- `src/ui/screens/SupportScreen.tsx` - показывать исследования БАДов

**Что делать:**
1. Добавить кнопку "📚 Исследования" в карточку препарата
2. При клике показывать модальное окно со списком исследований
3. Формат: `• Author A. et al., Journal Year — заключение`
4. Если исследований нет, показывать: "Исследования отсутствуют"

**Модальное окно (пример):**
```typescript
{showResearch && (
  <div style={{...}}>
    <h3>Исследования</h3>
    {research.length > 0 ? (
      research.map((r, i) => (
        <div key={i} style={{...}}>
          <strong>{r.study}</strong> ({r.year})
          <div>{r.conclusion}</div>
        </div>
      ))
    ) : (
      <div>Исследования отсутствуют</div>
    )}
    <button onClick={() => setShowResearch(false)}>Закрыть</button>
  </div>
)}
```

2. **Типы:** `npx tsc --noEmit` (должны быть ошибки только в тестах)

3. **Сборка:** `npx vite build` (должна пройти успешно)

4. **Русский язык:** Все тексты исследований на русском языке

## Примечания

- Исследования должны быть на русском языке (перевод с английских источников)
- Каждое исследование должно содержать: автор, журнал, год, заключение
- Заключение должно быть конкретным и научно обоснованным
- Не добавлять исследования без надежных источников (NEJM, Lancet, JAMA, etc.)
