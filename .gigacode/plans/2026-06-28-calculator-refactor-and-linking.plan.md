## АРХИТЕКТУРА (Логика работы)

### 1. Единый маппинг (основа всего)
```
Marker → Organ → System → Mechanism → CorrectionSubstance
Marker → PharmaDrug → Влияние (direction, severity) → Какие анализы сдавать
PharmaDrug → Week (start/end) → Эфир (накопление/выведение) → Понедельный риск
Substance → Synergy/Conflict → Разнос по времени ИЛИ исключение
UserData (всё) → тоже через маппинг
```

### 2. Принцип интеллектуального расчёта
- **Без привязки к ядру** — чистая математика: риск = f(маркеры, препараты, дозы, неделя)
- **Каждая кнопка (База/Средний/Макс) снижает риски ДО СРЕДНИХ значений** — меняется состав препаратов
- **Усиление** — апгрейд выбранного уровня элитными формами
- **Если не хватает уровня** → предупреждение перед планом «Рекомендуем уровень выше»
- **Joints/Связки/ОДА** — отдельная кнопка, НЕ участвуют в основном расчёте

### 3. Конфликт-чекер
- Сначала разносит по времени приёма (утро/день/вечер/ночь/натощак)
- ТОЛЬКО если разнести невозможно → исключает препарат

### 4. Понедельная динамика
- AAS: startWeek/endWeek → эфир накапливается/выводится → риск растёт/падает
- Поддержка меняется по неделям: дозировки, состав, риски
- Прогноз анализов на 2/4/6 недель

### 5. Save/Load
- **Единая панель** в подвкладке «Избранное» → подвкладка «Калькулятор»
- Сохраняется: ВСЕ вводные + план + результаты
- Комментарии: «Что сохраняется / Что загружается»
- Загрузка → восстановление всех полей + пересчёт с изменениями
