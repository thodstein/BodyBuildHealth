#### 1.2 Добавить из архива

**A. Периодизация (pereodization_engine.js → periodization.engine.ts)**
- `buildPeriodization()` - макроцикл (8-20 недель)
- `PHASES`: accumulation/intensification/transmutation/peak/deload
- `PERIODIZATION_TYPES`: linear/undulating/block
- SRA окна по качествам (strength/hypertrophy/power/endurance)
- `calcReadiness()` - на основе HRV, sleep, stress, soreness, mood
- `calcACWR()` - отношение острой/хронической нагрузки

- `buildDayContext()` - детальный контекст дня (qualityMix, energySystem, biomechBias, cnsState)

**C. Продвинутые методы (workout_planner.js → advanced-methods.engine.ts)**
- `ADV_METHODS_V1-V17` - 17 слоёв адаптации:
  - V6: recovery (sleep, HRV, stress)
  - V7: fatigue/adaptation/athleteProfile/CNS
  - V8: pain/risk/limitation/jointState
  - V9: fiberType/contraction/velocity/ROM
  - V10: zone/phase/microGoal/microAdaptation
  - V11: progression/energy/CNS/blockType
  - V12: torqueCurve/lengthTension/recruitment/forceVelocity
  - V13: momentArm/jointAngleStrength/synergy/motorLearning/RFD
  - V14: muscleArchitecture/stiffness/tendonElasticity/FTC/neuroRegulation
  - V15: viscoelasticity/passiveActiveTension/SSC/coordination
  - V16: damping/proprioception/reflex/noise/sensorimotor
  - V17: vestibular/visualMotor/auditoryMotor/RT/predictiveControl

**D. Шаблоны блоков (training_engine_block_templates.js → block-templates.engine.ts)**
- `getBlockTemplate()` - templates для goal×type×blockType×phase
- Типы: heavy_strength/medium_strength/hypertrophy_*/mixed_*/pump/technique
- BlockTypes: main/secondary/tertiary/accessory/skill/rehab/mobility
- Phase scaling (accumulation 1.0x → deload 0.5x)

### Phase 2: Интеграция

#### 2.1 training-full.engine.ts
```typescript
import { RIR_MATRIX, calculateWeeklyProgression } from './rir-matrix.engine';
import { generateMacrocycle, MesocyclePlan, Microcycle } from './training-periodization.engine';
import { selectSplit } from './split-selector.engine';

import { getBlockTemplate } from './block-templates.engine';        // new
import { applyAdvancedMethods } from './advanced-methods.engine';   // new

// Единая функция
export function generateCompleteTrainingPlan(input: TrainingInput): TrainingPlan {
  // 1. Macrocycle via periodization
  const macrocycle = buildPeriodization(input);
  
  // 2. Weekly progression via RIR matrix
  const weeklyProgression = calculateWeeklyProgression(input, currentWeek, totalWeeks);
  
  // 3. Select split
  const split = selectSplit(input);
  
  // 4. Block templates
  const blockTemplates = getBlockTemplate(input);
  
  // 5. Apply advanced methods
  const plan = applyAdvancedMethods(weeklyProgression, input);
  
  return {
    macrocycle,
    weekPlan: plan,
    notes: generateNotes(plan, macrocycle, split)
  };
}
```
